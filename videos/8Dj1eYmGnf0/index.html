- 사용언어 : Java, HTML, CSS, JavaScript
- 데이터베이스 : MariaDB, MongoDB
- 클라우드 : AWS
- 프로토콜 : SMTP, Https
- 기타 : JQuery, JPA
- IDE : IntelliJ
- API : 공공데이터포털 한국대학교육협의회 API, S3 Object Storage, 카카오 로그인 API
