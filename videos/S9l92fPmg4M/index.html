설 명 : 호구탈출 넘버원은 쇼핑품목의 쇼핑몰별 가격비교와 최저가 정보 제공을 위한 웹페이지이다. 크롤링을 활용하여 네이버 쇼핑의 데이터를 가져왔으며, 해당 데이터를 활용하여 쇼핑몰별 가격 차트와 최저가 정보를 제공한다. 또한 카테고리별로 브랜드 인기순위를 실시간으로 가져와, 워드클라우드로 시각화를 제공한다. 웹페이지에 로그인 할 경우에는 사용자의 권한에 따라서 기능을 나누었다. 관리자 권한을 가진 사용자로 로그인 할 경우, 회원관리 페이지에서 다른 회원들의 정보를 조회하거나 정보 혹은 권한 수정, 회원 삭제를 할 수 있다. 그리고 공지사항 게시, 수정, 삭제를 할 수 있게 설정했다. Ajax를 활용해서 로그인, 회원가입에 유효성 검사를 통해 관리하고, 쇼핑 물품 데이터를 불러오게 구현했다.

적용 기술
- 프레임워크 : 스프링프레임워크
- 데이터베이스 : MySQL, MongoDB
- 기타 : Ajax, Kakao REST API, AWS EC2, Jsoup, amChart
