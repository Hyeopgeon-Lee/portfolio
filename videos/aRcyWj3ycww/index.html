설 명 : My Recipe는 사용자에게 레시피의 정보와 식재료 가격, 효능 정보를 제공해 주는 서비스이다.

- 식재료 정보는 검색어를 통해 네이버 백과사전 API로 정보를 가져오고 가져온 링크를 Jsoup으로 크롤링하여 식재료의 효능 정보를 가져온 다음 사용자들에게 정보를 제공합니다 KAMIS에서 제공하는 가격정보를 API로 받아와서 제공합니다 식품의약품안전처의 조리식품의 레시피 DB API를 사용자들에게 레시피 정보로 제공합니다 소셜 로그인은 Security를 사용하여 만들었습니다

적용 기술

- 프레임워크 : Spring Boot
- 데이터베이스 : MariaDB, MongoDB
- 클라우드 : AWS EC2, RDS
- 기타 : Spring Boot, Spring Data JPA, AWS, Bootstrap, Spring MVC,
JQuery, Ajax, Jsoup, Tailwind, Spring Security
