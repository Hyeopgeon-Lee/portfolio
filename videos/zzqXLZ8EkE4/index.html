설 명 :
노래듣자 프로젝트는 크롤링 도구인 Jsoup를 이용하여 노래 정보를 가져와 사용자분들이 볼 수 있게 만든 웹입니다. 코모란과 armchart를 이용하여 카테고리별 top5노래 가사들의 빈도수에 따른 워드클라우드를 구현하였습니다. 또한 스케줄러를 활용하여 일정시간마다 크롤링 하여 저장한 노래 정보를 카테고리 별로 분류하여 사용자가 편리하게 볼 수 있게 하였고, 가사와 제목으로 노래를 검색할 수 있게 하였습니다. 로그인, 회원가입 시에는 Spring Security에 웹의 인증과 권한을 맡겼습니다.

적용 기술
- 프레임워크 : Spring Boot(Spring FrameWork)
- 데이터베이스 : Redis, MariaDB
- 기타 : Spring Security, AWS RDS, JPA, Jsoup, mustache, Jquery, AWS EC2, Bootstrap
