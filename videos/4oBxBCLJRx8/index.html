설 명 :
버억은 스프링 프레임워크를 활용한 햄버거 리뷰 반응형 웹입니다. 가입한 사용자들은 자신이 좋아하는 햄버거에 리뷰와 좋아요를 남길 수 있고 자유게시판을 통하여 사용자들 끼리의 소통을 가능하게 합니다. 가입한 사용자들의 데이터 기반으로 나이대나 브랜드의 선호하는 햄버거를 Landbot을 이용한 챗봇으로 확인이 가능하며 추천 햄버거를 사용자에게 제공하고 있습니다. 버억은 접속자의 위치를 기반으로 주변의 햄버거 가게를 찾을 수 있는 기능을 제공합니다. GeoLocation 기능을 사용하여 접속 위치의 정확성을 높였으며 해당 지역에 햄버거가게 브랜드를 검색하여 리스트로 제공합니다. 또한 지역별로 햄버거 가게를 검색할 수 있는 기능을 제공하고 있습니다.

적용 기술

- 프레임워크 : Spring Framework

- 데이터베이스 : Oracle11g

- 적용 API : LandBot , 카카오맵 , 카카오내비

- 기타 : Bootstrap
