작품 설명
본 서비스는 서울시 내 의류수거함의 접근성을 높이고 올바른 자원 순환을 돕는 위치 기반 스마트 의류 배출 서비스 입니다.
초정밀 위치 정보 제공: GPS를 활용해 사용자 주변 가장 가까운 수거함을 탐색하고, 단순 위치 표시를 넘어 카카오/네이버 지도 연동 길 찾기 및 로드뷰 미리보기를 통해 골목길에 숨겨진 수거함도 쉽게 찾을 수 있도록 지원합니다.
AI 기반 분리배출 가이드: 딥러닝 기반의 이미지 인식 기술을 탑재하여, 사용자가 의류 사진을 촬영하면 수거 가능 품목(헌 옷, 신발 등)과 불가능 품목(솜이불, 캐리어 등)을 즉시 판별하고 올바른 폐기 방법을 안내합니다.
사용자 참여형 데이터 갱신: 수거함의 실시간 상태(가득 참, 파손, 철거됨)를 사용자가 직접 제보하고 공유하는 커뮤니티 기능을 통해 헛걸음을 방지하고 데이터의 정확도를 높입니다.

적용 기술
프레임워크 : Spring Boot
사용 언어 : Java, HTML5, CSS, JavaScript
데이터베이스 : MongoDB (GeoJSON 기반 위치 데이터 저장)
클라우드 : AWS Amazon Web Services (EC2 , RDS)
데이터 처리 : CSV → MongoDB로 일괄 업로드
통신 방식 : REST API
기타 : jQuery, Ajax
IDE : IntelliJ, WebStorm
API: Kakao Maps API, OpenAI API

주요 기능
서울시 구별 수거함 위치 검색
드롭다운으로 구 선택 → 해당 구 내 수거함 지도에 마커 표시
사용자 위치 기반 주변 수거함 탐색
GPS 또는 브라우저 위치 기반 → 가장 가까운 수거함 조회 및 지도 표시
초정밀 위치 찾기: 내 위치 기반 가장 가까운 수거함 길 찾기 및 로드뷰 미리보기 제공
AI 스마트 분류: 사진을 찍으면 기부 가능 의류인지, 폐기물인지 즉시 판별 및 처리 방법 가이드
MongoDB 연동
CSV 파일로 정제된 위치 데이터를 MongoDB에 한 번에 업로드
컬렉션명: clothing_bin
재활용 이미지 업로드
ChatGPT Vision을 활용하여 이미지 분석 → 분리배출 방법 안내
Client: Kakao Maps API를 통해 지도 UI 렌더링 및 사용자 위치(GPS) 전송
Server: REST API를 통해 클라이언트 요청 처리 (GET /api/bins 등)
AI Service: OpenAI API와 통신하여 이미지 분석 결과 반환
