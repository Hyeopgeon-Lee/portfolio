작품 설명
MusicEmotionPRJ는 사용자의 텍스트 기반 감성을 분석하여 최적의 음악을 추천하는 감성 기반 음악 추천 플랫폼입니다.
사용자가 작성한 일기·문장·메모 등을 입력하면 OpenAI API를 활용한 감정 분석을 수행하고, 감정에 최적화된 Spotify 추천 음악을 제공합니다.사용자는 추천된 트랙을 저장하거나 삭제할 수 있으며, 감정 변화 기록과 음악 선택 패턴을 통계화하여 마이페이지에서 확인할 수 있습니다.

적용 기술
프레임워크: Spring Boot
사용 언어: Java, HTML5, CSS, JavaScript
데이터베이스 :
- MariaDB: 회원 정보, 추천 음악 기록, 감정 분석 결과
- MongoDB: 감정 로그, 비정형 분석 데이터
클라우드: Amazon Web Services (RDS)
통신 프로토콜: REST API
API 활용:
- OpenAI API: 감정 분석, 텍스트 해석
- Spotify API: 감정 기반 음악 추천
기타 :
MyBatis, Thymeleaf ,JQuery, Ajax
Jackson ObjectMapper,Maven
AI 기능 :
- OpenAI 기반 감정 분석
- 감정 키워드 기반 음악 추천 알고리즘
- 사용자 감정 기록 통계 생성
IDE : IntelliJ IDEA
