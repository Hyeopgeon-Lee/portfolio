설 명 : Animal Hospital은 동물병원의 위치제공 및 건의사항 수집 혹은 정보제공을 위한 웹페이지입니다. 서울열린데이터광장, 경기도 데이터 드림의 동물병원의 정보를 수집하여 api를 이용하여 지도에 마커와 인포윈도우를 나타내 동물병원 이름, 위치, 전화번호를 제공합니다. 로그인을 하면 메뉴가 사용자의 권한에 따라 표기가 됩니다. 관리자의 권한을 가진 사용자는 일반회원들이 쓴 정보를 조회, 수정, 삭제가 가능합니다. 그리고 관리자만이 공지사항을 작성할 수 있고 동물병원의 위치를 확인 할 수 있는 지도를 이용 가능합니다. 일반회원들은 공지사항 조회와 후기 작성 게시판에 글 등록, 수정, 삭제를 할 수 있고 지도에서 동물병원의 위치와 정보를 확인 할 수 있습니다.

적용 기술

- 프레임워크 : Spring Framework 4.0

- 데이터베이스 : Oracle SQL 11g

- 적용 공공데이터(OpenAPI) : 서울열린데이터광장, 경기도 데이터 드림 동물병원 정보 OpenAPI

- 기타 : ajax, summernote, 카카오 지도 api, HTML, JAVA, JSP, jQuery
