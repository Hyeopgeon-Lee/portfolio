설명 : 케어트랙은 의약품 API를 활용하여 의약품에 대한 정보를 사용자에게 제공하고 해당 정보를 통해 일정관리를 할 수 있도록 제공하는 웹서비스 입니다.
사용자들이 서로 커뮤니케이션을 통해 정보공유를 할 수 있도록 게시판과 웹채팅 서비스를 제공하고 있으며, 카드뉴스와 유튜브 API를 통해 사용자에게 다양하고 보기 좋은 건강정보를 제공합니다.

해당 서비스는 의약품을 모르고 복용하는 것이 아닌 알고 복용하자는 취지로 제작되었으며 시민들의 건강에 대한 관심도를 높일 수 있도록 기여하고자 합니다.

적용 기술

프레임워크 : Spring Framework

개발 언어 : Java, HTML, CSS, JavaScript

데이터베이스 : MariaDB, MongoDB

서버 : Amazon Web Service EC2

프로토콜 : WebSocket

API :식품의약품안전처 (의약품 제품 허가정보, 의약품 개요 정보), 로그인 API

기술 : Java, JPA, HTML, CSS, jQuery, Thymeleaf, AWS S3, OAuth

에디터 : IntelliJ

기타 : JQuery, JPA, Spring Security, Ajax, Thymeleaf
