작품 설명
서울시민을 위한 의류수거함 위치 검색 및 재활용 안내 서비스입니다.
서울 각 구별 수거함 위치를 조회하거나, 사용자 위치 기반으로 근처 수거함을 확인할 수 있으며,
AI 기반 이미지 인식을 통해 재활용 방법까지 안내하는 기능을 제공합니다.

적용 기술
프레임워크 : Spring Boot
사용 언어 : Java, HTML5, CSS, JavaScript
데이터베이스 : MongoDB (GeoJSON 기반 위치 데이터 저장)
클라우드 : AWS Amazon Web Services (EC2 , RDS)
데이터 처리 : CSV → MongoDB로 일괄 업로드
통신 방식 : REST API
기타 : jQuery, Ajax
IDE : IntelliJ, WebStorm
API: Kakao Maps API, OpenAI API

주요 기능
서울시 구별 수거함 위치 검색
드롭다운으로 구 선택 → 해당 구 내 수거함 지도에 마커 표시
사용자 위치 기반 주변 수거함 탐색
GPS 또는 브라우저 위치 기반 → 가장 가까운 수거함 조회 및 지도 표시
MongoDB 연동
CSV 파일로 정제된 위치 데이터를 MongoDB에 한 번에 업로드
컬렉션명: clothing_bin
재활용 이미지 업로드 (기획 중)
ChatGPT Vision을 활용하여 이미지 분석 → 분리배출 방법 안내
