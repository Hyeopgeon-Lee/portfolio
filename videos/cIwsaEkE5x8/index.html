설 명 :
항상 포털 사이트에서 뉴스를 보면서 제가 원하는 언론사나 주제만 보고 싶다고 생각했습니다. 내가 원하는 언론사와 주제를 선택하여 자신만의 뉴스피드를 구성해 원하는 뉴스만 볼 수 있는 사이트입니다. 뉴스에 대해 자신의 의견을 댓글로 남길 수 있지만 뉴스 그 자체만을 보고 싶어 하는 사람들을 위해 댓글을 안 볼 수 있게 댓글 기능을 차단할 수 있습니다. 또한 다시 보고 싶은 기사나 보다 만 기사들을 따로 저장하여 볼 수 있는 기능과 최근에 올라온 뉴스를 주제, 언론사와 무관하게 5개를 뽑아 보여주는 기능도 존재합니다. SpringBoot로 API서버를 구축하고 Node.js의 Express로 프론트 부분을 구축하여 만들었습니다.

적용 기술
- 프레임워크 : Spring Boot Framework, Node.js Express
- 클라우드 : AWS EC2, AWS RDS, Azure Virtual Machines
- 데이터베이스 : MariaDB, Redis
- ORM : Spring Data JPA
- 기타 : Axios(Ajax), Bootstrap, ES6
