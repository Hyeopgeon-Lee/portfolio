작품 설명
Hole In One은 회원(사장 및 직원)이 직접 가게의 메뉴를 등록하여 비회원(손님)이 등록된 메뉴를 조회할 수 있고 조회된 메뉴를 주문을 하여 해당 가게에 회원과 비회원 간에 인수인계를 편리하게 해줄 수 있는 시스템이다. 본 프로젝트는 Jquery의 Ajax를 통해 회원가입이 중복되지 않도록 철저하게 이루어지며, Kakao API를 이용하여 해당 가게의 주소를 등록할 수 있다. 메뉴 등록 및 주문은 Oracle SQL 11g를 활용하여 DB에 직접 등록되고 취소 할 수 있도록 되어 있다.
적용 기술
- 프레임워크 : Spring Framework 4.0
- 데이터베이스 : Oracle SQL 11g
- 적용 공공데이터(OpenAPI) : 회원가입 주소 조회 및 등록
- 기타 :
● Bootstrap 3.4.1
● Javascript
● Jquery 3.5.1
