작품 설명
BOOKIE는 AI 기반 기술과 외부 API를 활용하여
도서 탐색, 독서 기록, 생활 정보까지 통합 제공하는 스마트 독서 플랫폼입니다.

사용자는 관심 도서를 검색하거나 신간·베스트셀러 정보를 받아볼 수 있으며,
직접 읽은 책에 대한 독후감을 작성하고 저장할 수 있습니다.
또한, 날씨·대기질 정보 확인과 함께,
도서관·서점·카페 등의 장소도 쉽게 탐색할 수 있어
독서와 관련된 일상 활동을 효율적으로 지원합니다.

BOOKIE는 사용자에게 더 풍부한 독서 경험을 제공하고,
지속적인 독서 습관 형성과 정보 탐색의 편의를 통해
지적 성장과 삶의 질 향상에 기여합니다.

적용 기술
프레임워크 : Spring Framework
사용언어 : Java, HTML5, CSS, JavaScript
데이터베이스 : MariaDB(회원, 북마크, 독후감), MongoDB(독후감)
클라우드 : Amazon Web Services(EC2, RDS)
프로토콜 : HTTPS, SMTP
웹서버 : Nginx
API : 알라딘 상품리스트 API, Naver 검색 API, OpenWeatherMap API, Kakao 지도 API, Kakao 로컬 API
기타 기술 : Ajax, JQuery
IDE : IntelliJ, Webstorm
