설명 : REMENTIA는 치매 진단과 뇌 기능 트레이닝 서비스를 제공하는 플랫폼입니다.
REMENTIA는 치매의 영어 단어인 dementia와 회복을 의미하는 re- 접두사를 붙여서 만든 단어로,
치매 조기 발견과 인지 기능 회복을 기원하는 의미로 지은 이름입니다.
사용자는 화면에 제시되는 문장을 따라 읽는 것 만으로 간편하게 치매 위험도를 진단받을 수 있으며,
뇌 기능 트레이닝으로 인지 기능을 향상시킴으로써 치매를 예방할 수 있습니다.

적용 기술
- 프레임워크 : Spring Boot, Flask
- 사용언어 : Java, HTML5, CSS, JavaScript
- 데이터베이스 : MariaDB
- 클라우드 : Naver Cloud Platform
- 프로토콜 : WebSocket
- 기타 : JQuery, Ajax, MyBatis
- IDE : IntelliJ, PyCharm
- API : Amazon S3, Kakao Map, coolsms(Nurigo)
