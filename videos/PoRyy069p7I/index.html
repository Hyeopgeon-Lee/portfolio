설명 : Picasel은 인공지능을 활용한 아동 그림 심리 분석 서비스를 제공하는 플랫폼입니다.
Picasel은 그림과 상담을 뜻하는 영어 단어 picture와 counsel을 붙여서 만든 단어입니다.
사용자는 아동의 그림을 찍은 사진을 업로드하여 아동 심리를 분석 받을 수 있으며, 우울증 자가진단, 주변 아동심리 상담소 찾기, 상담 챗봇 서비스도 제공합니다.

적용 기술
프레임워크 : Spring Boot, Flask, Bootstrap
사용언어 : Java, HTML5, CSS, JavaScript, Python
데이터베이스 : MongoDB
클라우드 : AWS EC2, Naver Cloud Platform
프로토콜 : WebSocket
기타 : JQuery, Ajax, Thymeleaf, Amazon Bedrock
IDE : IntelliJ, PyCharm, WebStorm
API : Amazon S3, Amazon Lambda, Kakao Map, V-World, OpenAI, 랜덤 한국어 명언 API

주요 기능 목록:
1. 아동 그림 심리 분석 - 아동의 그림 파일에서 커스텀 학습시킨 YOLO로 객체를 인식한 결과 OpenAI API에게 전달하며 아동그림심리분석가의 역할로 분석 요청한 결과 제공
2. 우울증 자가 진단 - 아동청소년 우울증 자가 진단 문항 제공하고 사용자 제출로 점수에 따른 우울증 척도 표시
3. 근처 아동 상담소 찾기 - 현재 위치 좌표를 기반으로 아동복지시설 API에 요청하여 근처 아동 복지시설 정보(시설명, 전화번호, 주소 등)를 받아와서 카카오맵으로 정보 표시
4. 상담 챗봇 - 아동청소년 상담 데이터 기반으로 구현된 RAG 기반 실시간 TTS/STT 지원 챗봇
5. 마이페이지 - 그림 심리 분석 결과 조회 및 삭제, 자가진단 결과 조회 및 삭제, 분석/진단 결과 PDF로 받기, 비밀번호 변경, 회원탈퇴
6. 메인페이지 랜덤 명언 표시
