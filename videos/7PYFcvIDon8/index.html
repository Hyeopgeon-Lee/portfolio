설명 : 별 보러 갈래는 한국 천문 연구원OpenApi를 이용해
사용자에게 계절 별 별자리 정보와 월 별 우주 현상 정보를 제공하고,
지역에 따른 국내 천문대 정보를 제공하여 천체 관측에 대한 접근성을 높이는 웹 애플리케이션입니다.

또한 자유 게시판과 채팅 기능으로 사용자들 간의 소통도 활발히 이루어질 수 있습니다.

별자리 정보는 MongoDB에 저장하고 우주 현상 정보는 Ajax를 통해 RestApi를 호출합니다.

회원 정보는 MariaDB에 저장하며 채팅은 WebSocket을 이용하여 구현했고 채팅 내역은
Redis에 저장하고 메모리 과부하를 방지하기 위해 1주일 뒤에 자동으로 삭제됩니다.

적용 기술
-프레임워크 : Spring-Boot
-데이터베이스 : MariaDB, MongoDB, Redis
-클라우드 : AWS EC2, RDS
-기타 : Ajax, JQuery, Jsoup, Bootstrap, WebSocket, FullCalander, 도로명 주소 Api, Nasa OpenApi, Google Smtp
