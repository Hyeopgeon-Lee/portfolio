작품 설명

FROM은 AI 기반 기술과 외부 API를 활용하여 도서 검색, 독서 기록, AI 독후감 생성, AI 이미지 생성 기능을 제공하는 스마트 독서 플랫폼입니다.

사용자는 알라딘 Open API를 통해 원하는 도서를 검색하고 자신의 서재에 등록할 수 있으며, 완독한 도서에 대한 독서 기록을 관리할 수 있습니다. 등록된 도서는 개인 서재에서 관리되며 독서 이력과 함께 저장됩니다.

독서를 완료한 사용자는 AI 독후감 생성 기능을 활용할 수 있습니다. 사용자가 선택한 도서 정보를 기반으로 AI가 독후감을 자동 생성하며, 생성된 독후감은 MongoDB에 저장되어 마이페이지에서 다시 조회할 수 있습니다.

또한 AI 이미지 생성 기능을 통해 독서 경험을 시각화할 수 있습니다. 사용자가 읽은 도서의 내용과 분위기를 기반으로 AI가 이미지 생성 프롬프트를 작성하고, 생성된 이미지는 AWS S3에 저장된 후 서비스 내에서 확인할 수 있도록 구성하였습니다.

서비스는 독서 습관 형성을 지원하기 위해 독서 통계 기능을 제공합니다. 사용자는 월별 독서 권수, 연속 독서 일수, 독서 잔디, 최근 활동 내역 등을 확인할 수 있으며 자신의 독서 패턴을 시각적으로 분석할 수 있습니다.

또한 Redis 기반 주간 독서 랭킹 시스템을 구축하여 사용자의 독서 활동을 실시간으로 집계합니다. 독서 기록이 등록될 때마다 Redis Sorted Set을 활용하여 점수를 누적하며, 주간 독서 랭킹을 제공하여 사용자들의 독서 동기 부여를 지원합니다.

사용자는 도서 평점 및 독후감을 작성할 수 있으며 댓글과 좋아요 기능을 통해 다른 사용자와 독서 경험을 공유할 수 있습니다. 이를 통해 단순 독서 관리 서비스를 넘어 독서 기반 커뮤니티 기능을 제공합니다.

회원가입 시 이메일 인증 기능을 제공하며 JavaMailSender를 활용하여 인증번호를 발송합니다. 인증번호는 일정 시간 동안만 유효하도록 관리하여 보안을 강화하였습니다.

인증 방식은 Session 기반 인증 구조를 적용하였으며 Spring Session과 Redis를 활용하여 세션 정보를 중앙 저장소에서 관리합니다. 로그인 시 발급된 JSESSIONID를 통해 사용자 인증 상태를 유지하며 LoginInterceptor를 통해 인증이 필요한 요청을 검증합니다.

AI 서비스는 Claude API를 활용하여 독후감 생성 및 도서 추천 기능을 제공하며, Gemini AI를 활용하여 독서 이미지 생성 기능을 구현하였습니다. 또한 AI 추천 기능을 통해 사용자의 독서 활동과 관심 분야를 기반으로 맞춤형 도서를 추천합니다.

백엔드는 Spring Boot 기반으로 개발하였으며 Controller, Service, Repository 계층을 분리하여 유지보수성을 높였습니다. 데이터 저장소는 MariaDB, MongoDB, Redis를 함께 활용하여 정형 데이터, 비정형 데이터, 캐시 데이터를 목적에 맞게 분리하여 관리하였습니다.

배포 환경은 AWS 클라우드 기반으로 구축하였습니다. Spring Boot 애플리케이션은 AWS EC2 환경에서 운영하며, MariaDB는 AWS RDS를 사용하여 관리형 데이터베이스 환경을 구성하였습니다. 생성된 이미지 파일은 AWS S3에 저장하며, Nginx를 Reverse Proxy 서버로 활용하여 HTTPS 기반 서비스를 제공합니다.
