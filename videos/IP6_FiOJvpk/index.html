작품 설명

최근 개인화된 서비스의 수요가 증가하면서 사용자 개개인의 취향에 맞춘 콘텐츠 추천의 중요성이 높아지고 있습니다. 본 프로젝트는 사용자 간의 커뮤니티를 통해 얻은 피드백을 기반으로 개인 맞춤형 도서를 추천하여 독서 만족도를 높이고자 합니다. 또한, GPT API를 활용한 도서 추천, 캘린더를 통한 독서 기록 관리, 카카오 맵 API를 사용한 도서관 검색 등 다양한 기능을 제공하여 사용자 경험을 향상시키는 것을 목표로 하였습니다.

본 서비스는 사용자가 커뮤니티를 통해 도서에 대한 피드백을 제공하고, 이를 바탕으로 사용자 맞춤형 도서 추천을 받을 수 있도록 설계되었습니다. 독서 기록 관리와 도서관 검색 기능을 통해 사용자들이 더욱 편리하게 독서 생활을 즐길 수 있도록 지원합니다.

적용 기술

□ 프론트엔드: HTML, CSS, JavaScript, Thymeleaf

□ 백엔드: Spring Boot, MyBatis

□ 데이터베이스: MariaDB (사용자 및 게시판 데이터), MongoDB (댓글 데이터)

□ 클라우드 서비스: AWS (서버 호스팅), Naver Object Storage (프로필 이미지 저장)

□ 외부 API: GPT API (도서 추천), Kakao Map API (도서관 검색)
