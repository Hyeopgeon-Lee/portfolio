설 명 : “My Portfolio”는 개인 프로젝트(작업) 파일과 내용을 작성하고 작성된 내용을 바탕으로 웹 포트폴리오를 제작해주는 사이트입니다. 대시보드에서는 작성했던 프로젝트(작업)내용을 바탕으로 사용된 단어의 빈도수를 계산하여 워드클라우드를 표시합니다. 마이페이지에서 자신의 SNS주소를 입력하여 포트폴리오 페이지에 SNS링크를 나타낼 수 있습니다. “My Portfolio”는 앞으로 파일의 형상관리(이력관리)가 이루어질 수 있도록 개발을 이어 나갈 것입니다.

적용 기술
- 프레임워크 : Spring Framework
- 데이터베이스 : MySQL, Redis
- 기타 :
- Rserve(단어 빈도 수 분석)
- jQuery(비동기 서버통신 - ajax)
- MultiPartFile(파일 업로드 & 다운로드)
- amChart(워드 클라우드)
