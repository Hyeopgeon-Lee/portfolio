설 명 :

KIZ4는 유아와 함께 갈 수 있는 유아시설을 갖추고 있는 음식점이나 까페등을 사업자가 게시글을 통해 가게 위치와 이름, 갖추고 있는 시설들이나 가게의 특색을 설명해 작성하고 그것을 일반회원(사용자)가 보고 자신들이 원하는 곳을 찾아 갈 수 있게 도와주고 사용자가 찾아갔던 가게에 대한 리뷰를 작성함으로써 그 가게의 평판을 내려 다음 사용자들에게 선택의 도움을 주는 서비스입니다. 내 주변가게 위치 검색 기능으로는 내 접속 위치를 카카오 지도API와 GeoLocation 기능을 사용하여 정확성을 높이고 지도안에 가게 위치를 마커를 표시함으로써 확인이 쉽게 만들었습니다. 마커를 클릭 시 다음 길 찾기를 이용하여 특정위치에서 가게까지의 길 찾기가 가능합니다.

적용 기술

- 프레임워크 : Spring Framework

- 데이터베이스 : Oracle11g
- 적용 공공데이터(OpenAPI) :
- 기타 : 카카오 지도 API, Ajax, Javascript, jQuery, Bootstrap
