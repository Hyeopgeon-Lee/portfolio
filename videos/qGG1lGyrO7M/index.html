작품 설명

WingIt은 꿈을 찾는 사람들이 자신의 흥미와 가치관에 맞는 직업을 찾도록 돕기 위한 웹 서비스입니다.

정보가 넘쳐나는 시대에 무엇을 해야 할지 모르는 이들에게 정확하고 유용한 직업 정보를 제공하며, 잘 알려지지 않은 수많은 직업들을 사용자에게 소개해 새로운 진로를 탐색할 수 있게 합니다.

또한 사용자의 동기부여를 위해 실시간 화상채팅을 통한 스터디 기능을 제공하여, 함께 공부하고 정보를 공유하는 환경을 조성합니다.

적용 기술
- 프레임워크 : Spring Boot
- 사용언어 : Java, HTML5, CSS, JavaScript
- 데이터베이스 : MariaDB, MongoDB
- 클라우드 : Amazon Web Service
- 프로토콜 : WebSocket, WebRTC
- 기타 : JQuery, Ajax, MyBatis, Thymeleaf
- IDE : IntelliJ
- API : CareerNet Open API
