작품 설명
MauM은 현대인들의 일상 속 감정을 기록하고, 이를 AI로 분석하여 맞춤형 위로와 심리 케어를 제공하는 일기 기반 감정 분석 플랫폼입니다.

사용자는 매일의 일상을 일기 형태로 기록할 수 있으며, 입력된 일기 텍스트는 자연어 처리(NLP) 모델을 통해 기쁨, 슬픔, 분노, 불안 등 다양한 감정으로 자동 분류됩니다. 감정 분석 모델은 한국어 감정 분류 데이터셋(KOTE)을 활용하여 KoELECTRA 모델 사용 및 AI Hub의 데이터를 기반으로 klue/roberta-base 모델을 파인튜닝(Fine-tuning)하여 학습시켰으며 우울증을 분석하는데 활용했습니다.

분석된 감정 데이터는 마이페이지 및 대시보드 통계를 통해 시각화되어 사용자가 자신의 감정 변화 추이를 객관적으로 돌아볼 수 있게 돕습니다. 더 나아가, 사용자는 RAG(검색 증강 생성) 기술이 적용된 AI 챗봇과 대화하며 심리적 위로를 받을 수 있습니다. 이 챗봇은 네이버의 HyperCLOVA X 모델을 활용하며, MongoDB Atlas Vector Search를 통해 사용자의 과거 일기 및 감정 데이터를 벡터화하여 검색함으로써 개인의 맥락에 맞춘 깊이 있는 공감과 맞춤형 답변을 생성합니다.

카카오맵(Kakao Map) API를 연동하여 가까운 정신건강의학과 병원, 심리 상담 센터, 혹은 관련 지원 정책 정보를 지도 상에 마커로 시각화하여 안내합니다.

백엔드는 Spring Boot 기반으로 구축되었으며, JWT(JSON Web Token)와 Redis를 활용한 토큰 기반 인증 방식을 사용하였습니다. AI 모델 서빙 및 분석 서비스 영역은 Python, FastAPI, PyTorch를 활용하여 독립적인 API 서버로 구성하였고, 프론트엔드는 React를 기반으로 직관적이고 사용자 친화적인 웹 UI를 구현했습니다.

데이터 저장소는 서비스의 목적에 맞춰 회원 및 일반 관계형 데이터는 MariaDB에, 일기 텍스트 및 벡터 데이터를 포함한 비정형 분석 결과는 MongoDB에, 인증 토큰 및 캐싱 데이터는 Redis에 분리 저장하는 구조를 채택했습니다. 배포 환경은 Google Cloud Platform(GCP) 상에서 Docker와 Nginx를 활용해 구축하여 실제 웹 서비스 형태로 원활하게 운영되고 있습니다.

적용 기술

프레임워크 : Spring Boot, FastAPI, React

프론트엔드 : React, HTML5, CSS, JavaScript, Kakao Map API

백엔드 : Spring Boot, Spring Security, JWT

AI 서비스 : Python 3, PyTorch, FastAPI, KoELECTRA, klue/roberta-base, HyperCLOVA X, Hugging Face

데이터베이스 : MariaDB (관계형 데이터), MongoDB (Vector Search 및 비정형 데이터), Redis (인증 토큰 관리)

클라우드 및 배포 : Google Cloud Platform (GCP), Nginx, Docker

인증/보안 : JWT 기반 인증, Redis 인증 정보 관리, Spring Security
