작품 설명
AGRIWATCH는 사용자의 지역 정보와 작물 정보를 기반으로 농작물 재배 분석과 병충해 진단을 지원하는 AI 기반 스마트 농업 지원 플랫폼입니다.

사용자는 지역을 선택한 뒤 해당 지역의 기상 정보와 농업 데이터를 기반으로 추천 작물을 확인할 수 있으며, Google Gemini AI가 추천 이유, 재배 방법, 위험 요소 등을 자연어로 제공합니다.

또한 작물 이미지를 업로드하면 AWS S3에 이미지를 저장하고, Presigned URL을 통해 Gemini AI가 이미지의 시각적 특징을 분석합니다. 이후 공공데이터포털의 병충해 정보와 비교하여 가능성이 높은 병충해 진단명, 증상 요약, 해결 방법, 예방 방법을 제공합니다.

회원가입, 로그인, 이메일 인증, 아이디 찾기, 비밀번호 찾기 기능을 제공하며, Redis를 활용하여 이메일 인증번호와 사용자 세션을 관리합니다. 사용자의 작물 분석 결과와 병충해 진단 결과는 MariaDB에 저장되어 마이페이지에서 다시 확인할 수 있습니다.

본 서비스는 Spring Boot 기반 MVC 구조로 구현되었으며, AWS EC2, RDS, S3, Redis, Docker, Nginx, HTTPS, SSL 환경을 활용하여 실제 웹 서비스 형태로 배포 및 운영됩니다.

적용 기술

프레임워크 : Spring Boot 3.x, Spring MVC

사용 언어 : Java 17, HTML5, CSS, JavaScript

데이터베이스 : MariaDB, Redis

클라우드 : Amazon Web Services(EC2, RDS, S3)

웹서버 / 배포 : Nginx, Docker, HTTPS, SSL 인증서

통신 프로토콜 : REST API, HTTPS, SMTP

인증 / 세션 관리 : Session 기반 로그인, Spring Session Redis, Redis 이메일 인증번호 관리

AI 활용 : Google Gemini API
작물 추천 분석, 병충해 이미지 특징 추출, 병충해 진단 결과 생성

API 활용 : Google Gemini API, 기상청 API 허브, 공공데이터포털 API, NAVER Maps API

공공데이터포탈 목록 : 기상청_작물별 농업주산지 상세날씨 조회서비스, 농림수산식품교육문화정보원_작물농업 작물재배 정보, 농림수산식품교육문화정보원_영농가이드 병충해

기타 : Thymeleaf, RestClient, Lombok, Gradle
