살펴보세요.

설명 : Balance Fit은 사용자가 건강하게 다이어트를 할 수 있도록 분야별 식단, 식품 영양정보, 운동 관리를 해주는 서비스입니다.
균형 잡힌 영양소로 구성하여 분야별 여러 식단 정보를 추천해 주고, 식품의약품안전처의 식품 영양성분 DB API를 가져와 사용자들에게 영양성분 정보를 제공합니다.
사용자의 하루 식사한 총칼로리를 BMR 계산법을 통해 운동 소모 칼로리를 알 수 있도록 하여 체계적으로 다이어트를 할 수 있고, 커뮤니티 게시판을 통하여 관리자에게 다이어트 관련 상식이나 다이어트에 도움 되는 정보를 받을 수 있습니다.
Kakao Map API를 사용하여 키워드로 다이어트 추천 식당 장소를 검색하여 위치 정보를 얻을 수 있으며, WebSocket을 활용한 채팅을 통해 고객센터 및 사용자 간 1대 n 채팅을 이용할 수 있습니다.
사용자가 관리자에게 메일 발송하여 사용 관련 문의를 할 수 있습니다.

적용 기술
- 프레임워크 : Spring-Boot
- 데이터베이스 : MariaDB
- 클라우드 : AWS EC2, RDS
- 프로토콜 : WebSocket
- 기타 : Spring Data JPA, MyBatis, Java, HTML, CSS, JavaScript
- API : 식품영양성분DB API, Kakao API, Naver Papago 번역 API, 언어감지 API
