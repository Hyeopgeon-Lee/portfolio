설명 : oisomarket은 사용자가 회원가입 후 로그인해서 상품을 등록하고 다른 사용자의 상품과 교환을 신청할 수 있는 웹서비스입니다.

일반적인 중고거래 서비스처럼 상품 목록, 상품 상세보기, 카테고리 조회, 내 상품 관리 기능이 있고 교환 신청이 이루어지면 사용자끼리 채팅할 수 있도록 채팅방도 생성되는 구조입니다.

또한 상품 등록 시 안전하지 않은 상품이 등록되지 않도록 금지 키워드 검사와 Safety Korea API 리콜 상품 검사를 적용했습니다.

적용 기술

개발언어 : Java, HTML, CSS, JavaScript
백엔드 프레임워크 : Spring Boot
프론트엔드 : HTML, CSS, JavaScript, Thymeleaf
데이터베이스 : MariaDB, MongoDB
데이터 접근 : Spring Data JPA, Hibernate
클라우드 : AWS EC2, AWS RDS, AWS S3
이미지 저장 : AWS S3
로그인/인증 : HttpSession 기반 로그인
외부 API : Safety Korea API
외부 API 통신 : RestClient
웹서버 : Nginx
통신 방식 : HTTP, HTTPS, GET, POST, JSON, Form Submit
