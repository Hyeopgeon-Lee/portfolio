설 명 : HeartBeat는 자동심장충격기의 위치제공 및 건의사항 수집 혹은 정보제공을 위한 웹페이지이다. 공공데이터인 자동 심장충격기 정보 api를 이용하여 지도에 마커와 인포윈도우를 나타내 위치제공 및 부가설명을 제공한다. 로그인을 할 경우에 사용자의 권한에 따라 메뉴가 표시된다. 관리자의 권한을 가진 사용자는 관리자페이지를 통해 회원들을 정보를 조회하거나 수정, 삭제를 할 수 있다. 그리고 공지사항 게시판에서 관리자의 권한을 가진 경우에만 글을 작성, 수정, 삭제 할 수 있게 설정했다. 관리자는 사용자의 구분없이 모든 사용자의 글을 수정, 삭제 할 수 있다. 지도와 글을 조회하는 경우 로그인이 없어도 이용이 가능하고 글을 작성하거나 관리할 경우 로그인이 필요하다. 로그인과 회원가입은 AJAX를 이용한 유효성 검사를 통해 관리한다.

적용 기술

- 프레임워크 : 스프링 프레임워크

- 데이터베이스 : 오라클

- 적용 공공데이터(OpenAPI) : 공공 데이터 포털 자동심장충격기 정보 OpenAPI

- 기타 : ajax, summernote, 카카오 지도 api
