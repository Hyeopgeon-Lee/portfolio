설 명 : Around-Sell은 가입한 지역구를 기반으로 상품 판매 정보를 시각화하여 제공하는 쇼핑 도우미 웹 애플리케이션입니다.
로그인 시 가입 지역의 날씨와 대기환경 정보를 크롤링과 공공데이터를 통해 제공합니다.
동적 쿼리를 활용하여 다양한 검색 타입을 지정하여 검색이 가능하며, 가입한 지역의 판매 상품 정보와 지도 api를 통해 위치 정보를 제공합니다.
또한 길찾기 기능과 아임포트 api를 이용한 모의 결제를 지원합니다.
댓글에 오피니언 마이닝을 통한 긍정, 부정 결과를 보여주며, 회원을 위한 장바구니와 최근 본 상품, 최근 검색어 기능을 제공합니다.
인기 상품에 대해 워드클라우드와 차트로 시각화하며, 각 차트 탭을 클릭하면 관련된 상품 데이터로 검색 결과를 보여줍니다.

적용 기술
- 프레임워크 : Spring Framework
- 데이터베이스 : MariaDB, Redis
- 클라우드 : AWS EC2, RDS, Route53
- 기타 : Ajax, jQuery, Jsoup, Bootstrap, Amcharts, Kakao map api, 도로명주소 api, 아임포트 api, 서울시 대기환경 공공데이터
