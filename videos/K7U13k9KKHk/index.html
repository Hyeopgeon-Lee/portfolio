설 명 : Opencv를 활용한 근태관리 시스템 오근태는 Opencv 기술을 통해 사람의 얼굴을 인식하여
출근 시간과 지각 정보를 체크하여 관리자에게 알려주는 서비스입니다.
오근태는 세 가지 서버로 구성됩니다. 첫 번째는 Flask Framwork와 파이선 언어로 개발한 API서버,
Spring Framework와 자바로 구성된 Spring 서버, 데이터를 저장할 데이터베이스 서버로 구성되고,
데이터베이스 서버는 정형데이터를 저장하는 MariaDB와 비정형 데이터를 저장하는 MongoDB로 개발하였습니다.
API서버는 Opencv 패키지와 하르 분류기를 통해 사람의 얼굴을 학습하고, 사람의 얼굴을 인식한 시간을
체크하여 Spring서버로 데이터를 전송합니다. Spring 서버는 API 서버로 부터 받은 데이터를 가공하여
마지막으로 데이터베이스서버로 보냅니다.
Spring 서버는 출근 한 사람의 정보와 지각 유무를 대시보드에서 한 눈에 확인을 할 수 있으며 등록된
사람들에게 메일을 발송할 수 있습니다.

적용 기술

- 프레임워크 : Spring Framework, FlaskFramwork
- 데이터베이스 : MongoDB, MariaDB
- 클라우드 : AWS EC2, RDS(MariaDB)
- 기타 : Opencv-python, Opencv-contrib, psutil, Ajax, jQuery
