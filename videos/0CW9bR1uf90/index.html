설 명 :
TSHOP은 미니 쇼핑몰 웹 어플리케이션입니다. 아임포트 API를 활용하여 모의 결제를 할 수 있습니다.
사용자가 해당 상품을 구매할 때 KOMORAN API를 활용하여 상품 리뷰의 워드클라우드를 통해 가시화 하여
사용자에게 편의성을 제공합니다. 기본적인 회원 가입 외에도 KAKAO REST API를 활용하여 카카오 로그인을 할 수 있습니다.
WebSocket을 이용한 채팅서비스를 이용 할 수 있고 TTS(Text to Speech)와 STT(Speech to Text)를 활용한 채팅을 할 수 있습니다.

적용 기술

- 프레임워크: Spring Framework
- 데이터베이스: MySQL
- 기타: AWS EC2, AWS RDS, WebSocket, jQuery, KAKAO REST API, Komoran API, 아임포트 API
