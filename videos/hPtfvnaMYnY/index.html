설 명 : Foody는 음식이미지를 분석하여 음식이름을 제공하는 앱 서비스입니다. Foody는 많은양의 음식 이미지를 바탕으로 TensorFlow를 활용하여
음식 이미지를 분석하여 음식 이름과 알레르기 성분을 제공합니다. 또한 성분표 이미지를 OcrAPI를 활용하여 여러국가의 언어로 번역하여 제공합니다. 여러가지 한국음식을 소개하며, 한국음식 속 알레르기 정보를 제공합니다. 회원들은 게시판에서 자신의 글을 등록, 조회, 수정, 삭제가 가능하고 다른 사용자의 글을 조회 할 수 있습니다.

적용 기술

- 프레임워크 : Spring Framework, Flask

- 데이터베이스 : MySQL, Redis

- 클라우드 : AWS EC2

- 기타 : Tensorflow
