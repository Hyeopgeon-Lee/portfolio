설 명 : LAP는 노래 순위 차트에 노래 가사들을 분석하는 웹페이지 형식의 서비스입니다. LAP는 Bugs 뮤직 차트 정보를 크롤링하여 Bugs 뮤직 차트를 보여줍니다. 크롤링한 데이터를 기반으로 뮤직차트의 노래가사들을 감정분석을 하여 각도차트에 긍정적인 감정이 몇 퍼센트인지 보여줍니다. 뮤직차트의 노래가사들을 komoran형태분석기를 사용하여 노래 가사들을 정제하고 Word Cloud로 띄어줍니다. 로그인을 하면 메뉴가 사용자의 권한에 따라 표기가 됩니다. 일반회원들은 게시판에서 자신의 글을 등록, 조회, 수정, 삭제가 가능하고 다른 사용자의 글을 조회 할 수 있습니다. 관리자의 권한을 가진 사용자는 일반회원들이 쓴 정보를 조회, 수정, 삭제, 등록이 가능합니다.

적용 기술

- 프레임워크 : Spring Framework 4.0

- 데이터베이스 : MySQL, MongoDB

- 클라우드 : AWS EC2

- 기타 : Ajax, jQuery, Jsoup, komoran형태분석기
