작품 설명
GagyeView는 AI와 OCR 기반 기술을 활용하여
영수증의 항목을 자동으로 분류하고 시각화된 가계부 형태로 제공하는 금융 플랫폼입니다.
사용자는 영수증을 촬영하거나 업로드하여 소비 내역을 자동으로 등록할 수 있으며,
AI가 카테고리별로 소비 유형을 분류하고, 시각화 도구를 통해
월간 소비 흐름 및 이상 지출 패턴을 한눈에 확인할 수 있도록 지원합니다.
이 플랫폼은 사용자의 소비 습관 개선 및 재정 건전성 향상에 기여합니다.

적용 기술
- 프레임워크 : Spring Framework
- 사용언어 : Java, HTML, CSS, JavaScript
- 데이터베이스 : MariaDB, MongoDB
- 클라우드 : AWS EC2
- 프로토콜 : SMTP, HTTPS
- 기타 : Ajax, JQuery, Bootstrap, Fabric.js, Apache ECharts
- IDE : IntelliJ
- API : Google Cloud Vision API, OpenAI GPT API, Kakao Map API
- 웹서버 : Nginx
