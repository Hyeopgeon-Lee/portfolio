설 명 :
매일 우리는 무슨 날씨이고 무슨 옷을 입어야 할지 고민합니다. 요즘 트렌드는 어떻고 날씨는 어떤지, 외부 로그인으로 빠르고 간편한 사이트 이용과 오늘 하루를 간단한 사진 한 장으로 추억을 저장하고 볼 수 있는 사이트입니다. 지역별 날씨와 최신의 옷을 추천해주는 기능 또한 있습니다. SpringBoot를 이용한 API서버 구축과 RDS를 이용해 Maria DB를 연동했고, S3를 이용해 저장했습니다. mustache를 이용해 프론트부분을 만들었습니다.

적용 기술
- 프레임워크 : Spring Boot Framework
- 클라우드 : AWS EC2, AWS RDS, AWS S3
- 데이터베이스 : MariaDB, MongoDB
- ORM : Spring Data JPA
- 기타 : Ajax, Bootstrap, mustahe
