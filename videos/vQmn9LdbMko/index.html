살펴보세요.

설명 : WORDBOOK은 단어를 검색하고, 단어장에 저장하며 이를 기반으로 단어문제를 풀이해 단어 학습에 도움을 주는 앱입니다.

또한 공부메모장을 통해, 학습 도중 필요한 메모장으로 사용할 수 있으며, 캘린더를 통해 학습 기록과 개인 스케줄을 관리 가능합니다.

적용 기술

- 프레임워크 : Spring-Boot, ReactJS

- 사용언어 : Java, HTML, JavaScript, JSX

- 데이터베이스 : MariaDB, MongoDB

- 클라우드 : Amazon Web Services, Naver Cloud Platform

- 프로토콜 : HTTP, SMTP

- 기타 : Spring Data (JPA, MongoDB), MUI, React Router, AXIOS, fullcalendarJS,

- IDE : IntelliJ, WebStorm

- API : 국립국어원 표준국어대사전 OpenAPI, Naver API(로그인, 오타검색)
