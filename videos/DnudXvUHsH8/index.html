작품 설명
CineView는 TMDB 영화 데이터 API와 Kakao Maps API를 활용하여
사용자가 원하는 영화를 검색하고 감상평을 작성할 수 있는 웹 기반 영화 리뷰 플랫폼입니다.
사용자는 영화 제목으로 검색 후 상세 정보를 확인할 수 있으며,
직접 작성한 감상평은 MongoDB에 저장됩니다.
또한 Kakao 지도 API를 통해 현재 위치 기반 근처 영화관 정보를 확인할 수 있어,
영화 감상과 관련된 정보 접근성과 사용자 편의성을 높였습니다.
CineView는 사용자 중심의 직관적인 UI와 실시간 비동기 처리로 쾌적한 리뷰 작성 환경을 제공합니다.

적용 기술
프레임워크 : Spring Boot
사용언어 : Java, HTML, CSS, JavaScript, JSP
데이터베이스 : MariaDB, MongoDB
클라우드 : AWS EC2
프로토콜 : SMTP, HTTPS
기타 : Ajax, JQuery, MyBatis, Lombok
IDE : IntelliJ
API : TMDB API, Kakao Map API
웹서버 : Nginx
