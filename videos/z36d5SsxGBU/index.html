설 명 :

최근 ‘결정장애’라는 말이 생기고 있습니다. 식사 하나를 할 때도 무엇을 먹을까 고민을 하는 사람들이 늘어나고 있고 그런 사람들에게 식사를 추천해주는 웹사이트를 만들어보고 싶어 만들게 되었습니다. 다양한 음식리스트를 json파일로 만들어 먹을 시간, 원하는 가격을 적으면 랜덤하게 추천해주는 ‘랜덤 뽑기’기능과 내가 무엇을 먹고 싶은지 알고싶을 때에 계속 해서 질문을 던져주는 ‘스무고개 음식 뽑기’ 기능을 만들었습니다. 위 두 기능은 비로그인 상태에서도 사용가능하며 로그인한 사용자들은 json파일에 있는 음식리스트중 두가지 음식을 선정하여 무엇을 먹어야 할지 투표를 할 수 있게 투표게시판을 만들어 이용할 수 있게 하였습니다.

적용 기술

- 프레임워크 : SpringFramework

- 데이터베이스 : Oracle 11g

- 적용 공공데이터(OpenAPI) : 한국소비자원 가격정보서비스

- 기타 : Kakao Map API, Javascript, jQuery, 썸머노트, Bootstrap
