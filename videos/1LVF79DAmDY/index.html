작품 설명
Business Navigator는 서울에서 창업하고자 하는 예비 사장님들을 위해 업종의 현황 데이터를 가공하여 시각화 해주는 시장 분석 서비스 입니다.
서울 전체 기준 업종 현황과 추이를 파악 할 수 있습니다.
원하는 업종과 창업하고자 하는 지역을 선택하여 자세한 업종 분석 데이터를 제공 받을 수 있습니다.
자신이 마음에 드는 업종과 지역을 관심 업종에 등록하여 편하게 현황을 볼 수 있습니다.
또한, 사용자는 YouTube Data API에서 제공하는 영상을 통해 창업 아이템 추천을 받을 수 있습니다.

적용 기술
- 프레임워크 : Spring-Boot
- 사용언어 : Java, HTML, CSS, JavaScript
- 데이터베이스 : MariaDB, MongoDB, Reids
- 클라우드 : Amazon Web Services
- 기타 : JPA(Hibernate), Ajax, BootStrap, Thymeleaf
- IDE : IntelliJ
- API : 서울 공공데이터 API (서울 전체 매출액, 서울 전체 점포 데이터), Kakao Map API, YouTube Data API
