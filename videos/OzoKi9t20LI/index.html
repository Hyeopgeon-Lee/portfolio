설명 : 사용자 처방 내역 조회 및 복약 관리 서비스

하루약속은 처방 내역 조회부터 복약 알림, AI 약사 상담, 약국 검색까지 제공하는 통합 복약 관리 서비스 입니다.
사용자의 간편 본인 인증을 통해 처방 내역을 동기화 및 조회하고, 그 중 본인이 관리 받을 처방을 선택할 수 있습니다.
사용자가 복약 관리 설정한 처방의 경우 자동으로 복약 일정을 생성하고 복약 시간에 알림 메일을 전송합니다.
AI 약사 상담을 통해 사용자는 증상에 따라 약품 및 행동을 추천 받을 수 있습니다.
약국 검색 기능을 통해 사용자 주변 혹은 타 지역의 약국의 정보를 검색할 수 있습니다.

적용 기술
프레임워크 : 스프링부트
사용언어 : Java, HTML5, CSS, JavaScript

기타 : jQuery, Ajax
IDE : IntelliJ
API :
- TILKO API : 본인 인증 및 사용자 처방 내역 조회
- OPENAI API : 처방 데이터 전처리 / AI 상담 챗봇
- KAKAO MAP API : 사용자 위치 주변 / 타 지역 약국 찾기
