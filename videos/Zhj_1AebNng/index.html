설 명 :

맛집 추천 웹사이트 푸디봇은 서울 내 맛집들의 정보를 제공하고 챗봇을 통해 사용자에게 맛집 추천을 하는 서비스입니다. 파이썬 크롤링을 통해 타 웹사이트에서 맛집 정보 데이터베이스를 구축했으며 카카오 지도 API를 이용해 지도에 맛집 위치 정보를 나타냈습니다. 사용자의 현재 위치는 Geolocation API를 통해 지도에 나타내 사용자가 본인의 위치를 지도에서 확인 후 근처 맛집 정보를 찾아 볼 수 있도록 했습니다. 푸디봇은 맛집 정보를 카테고리 별로 제공할 뿐만 아니라 검색기능을 통해 상호명, 또는 카테고리를 직접 검색할 수 있습니다. 추후 푸디봇은 더 다양한 맛집 정보를 업데이트 할 예정이며 서울 뿐만 아니라 전국적인 맛집 정보를 제공 할 예정입니다.

적용 기술
- 프레임워크 : 스프링 프레임워크
- 데이터베이스 : 오라클
- 적용 공공데이터(OpenAPI) : 카카오 지도 API
- 기타 : 파이썬 크롤링, Geolocation API, Landbot
