설명 : 물날은 기상청 API와 인공지능 음성 합성 기능을 통해 사용자가 설정한 위치의 해상 날씨를 실시간으로 제공하는 웹앱 플랫폼입니다.

기존 복잡한 해상 날씨 제공 사이트들의 문제점을 개선하여 바다 날씨를 한 눈에 알 수 있게 보기 쉬운 UI/UX를 제공합니다. 또한, 사용자들은 캘린더를 통해 선박 등의 일정 관리가 용이해지고 연간 통계 데이터 제공으로 효율적인 성과 관리가 가능해집니다.

물날은 해양과 관련 된 더 많은 정보를 제공할 수 있도록 지속적인 개발 중에 있습니다.

적용 기술

- 프레임워크 : Spring Boot

- 개발 언어 : Java, HTML, CSS, JavaScript

- 데이터베이스 : MariaDB, MongoDB

- 클라우드 : AWS

- 기타 : JQuery, JPA, MyBatis, Spring Security, Ajax, Thymeleaf, Bootstrp, S3, OpenFeign

- IDE : IntelliJ

- API : 기상청 API, Google Text-to-Speech API, Kakao Map API, Kakao Login API, Naver Login API
