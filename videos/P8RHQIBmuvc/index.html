설 명 :
NBA는 네이버 농구에서 항상 상위권을 점유하고 있는 뉴스임에도 불구하고 해외농구가 없습니다. 저는 ‘해외축구처럼 해외농구 위주로 간편하게 보고 싶다.’ 라는 생각을 하여 이 웹사이트를 만들게 되었습니다. 주요기능은 스포츠 뉴스에 이 시각 많이 본 농구 뉴스를 크롤링 해옵니다. 그 기사가 긍정적인 기사인지 부정적인 기사인지 알아볼 수 있도록 오피니언 마이닝 기술을 적용시키고 수치화 하였습니다. 제목을 클릭하면 오피니언 마이닝 결과와 함께 뉴스기사로 연결 가능한 버튼이 존재합니다. 또한 기사 제목에 사용된 단어들을 텍스트 마이닝 기술을 통해 형태소 분석 후 d3.WordCloud를 이용해 어떤 단어가 많이 사용되었는지 한눈에 시각화 하였습니다. Node.js의 Socket.io를 활용한 실시간 채팅서비스로 사용자들이 자유롭게 채팅할 수 있도록 구성하였고 Kakao RestAPI를 활용하여 간편하게 로그인 할 수 있게 만들었습니다. 관리자 페이지는 워드클라우드에 사용된 단어 중 부적절 하다고 판단되는 단어를 임의로 삭제할 수 있게 만들었습니다.

적용 기술
- 프레임워크 : Spring framework, Bootstrap, 오피니언 마이닝, 텍스트 마이닝
- 데이터베이스 : Mysql, mongoDB
- 클라우드 :　AWS EC2
- 기타 :Javascript, jQuery, d3.WordCloud, Node.js, Kakao RestAPI
