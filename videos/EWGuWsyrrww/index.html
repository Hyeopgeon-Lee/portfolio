작품 설명
K-Stock Compass는 복잡한 재무제표 대신 AI 기반 5단계 신호등으로 상장기업의 재무 안정성을 직관적으로 제공하는 주식 재무 분석 플랫폼입니다.

한국투자증권 Open API를 통해 실시간 주가 및 시장 지수를 조회할 수 있으며, DART 전자공시 API로 수집한 재무제표 데이터를 Gemini AI가 분석하여 1~5점의 신호등 점수와 자연어 해설을 자동 생성합니다.

사용자는 관심종목을 등록하고 목표가 도달 시 실시간 알림을 받을 수 있으며, 보유 종목 포트폴리오 관리와 수익 시뮬레이션 기능을 통해 투자 전략을 체계적으로 수립할 수 있습니다.

JWT 기반 Stateless 인증 구조와 Redis 다중 캐싱을 적용하여 보안성과 성능을 동시에 확보하였으며, AWS EC2 환경에 Docker 기반으로 배포하여 운영하고 있습니다.

적용 기술
프레임워크 : Spring Boot 3.x, Spring Security

사용 언어 : Java 17, HTML5, CSS, JavaScript

데이터베이스 : MariaDB (회원, 관심종목, 알림, 게시판, 포트폴리오 등), Redis (Refresh Token, 인증번호, 주가, 환율, AI 분석 데이터 캐싱)

클라우드 : Amazon Web Services EC2, Docker

통신 프로토콜 : REST API, HTTPS, SMTP

웹서버 : Nginx (리버스 프록시, SSL)

인증/보안 : JWT Token, AES-128 CBC 암호화, BCrypt

API 활용 : 한국투자증권 Open API, DART 전자공시 API, Google Gemini API, 한국은행 ECOS API, 기상청 공공데이터 API

기타 : Thymeleaf, WebClient, JPA/Hibernate, Redis
