설 명 : frEEEbook은 YES24와 교보문고의 무료 전자책 연결 웹 어플리케이션입니다. 각 사의 무료 전자책 정보를 수집후 최신 20개 도서를 출력합니다.
제목, 작가, 출판사, 장르 카테고리 별 검색을 구현하였고 여러 도서를 랜덤으로
출력하는 도서 추천 기능을 제공하며 TTS 음성을 지원하는 E북을 따로 볼 수
있게 분류하였습니다. Komoran 형태소 분석기와 amChart를 이용한 워드 클라우드를
통해 1만개 이상의 도서 제목 데이터를 제공함으로 검색에 편의성을 제공합니다.

적용 기술
- 프레임워크: Spring Framework
- 데이터베이스: MySQL, MondgoDB
- 기타: Jsoup, amCharts, jQuery, Komoran, AWS EC2, AWS RDS
