설 명 :

오늘의당은 식품영양성분 공공데이터를 활용한 식품 영양 검색 및 관리

웹서비스로 개인프로젝트 웹 구현을 위해 개발했다. 오늘 먹은 음식의

성분들에 무엇이 들었는지 궁금한 사람들을 고려하여 본인이 먹은

음식의 키워드를 검색하면 키워드를 토대로 키워드에 포함되어 있는

식품 리스트가 조회가 되며 식품들의 영양 성분들을 간편하고 빠르게

조회 할 수 있다. 본인이 먹은 음식들을 추가하여 오늘 먹은 음식들의

영양 성분들이 얼마나 되는지 오늘 먹은 식품 목록에서 식품의

영양 성분들과 식품의 이름을 각자 확인 할 수 있다. 해당 웹 구현을

통하여 사용자들이 본인의 식품영양성분을 더욱 쉽게 조회하고 오늘 먹은

음식들의 성분들과 종류를 더욱 더 쉽게 관리 할 수 있을 것이다.

적용 기술

- 프레임워크 : Spring FrameWork

- 데이터베이스 : Oracle11g

- 적용 공공데이터(OpenAPI) : 식품영양성분DB

- 기타 :

1. Ajax

2. Bootstrap 4.0

3. Jquery v2.2.4

4. 비밀번호 SHA256 해시함수 적용
