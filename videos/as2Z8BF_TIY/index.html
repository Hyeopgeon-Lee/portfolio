작품 설명
TRADEMON은 투자에 관심 있는 사용자들을 위한 모의 투자 및 분석 플랫폼입니다.
실시간 금융 데이터와 공공 API를 기반으로 주식 및 암호화폐의 시세 조회, 공시자료 열람, 투자 지표 분석 기능을 제공합니다.

또한, 사용자는 제공된 가상 자산으로 주식과 코인을 매매하며, 자신의 투자 내역을 대시보드를 통해 한눈에 파악할 수 있습니다.
뉴스 스크랩 기능, 경제·경영 용어 검색, 공시자료 열람을 통해 투자에 필요한 정보들을 체계적으로 관리할 수 있으며,
실제 거래가 아닌 시뮬레이션 기반의 안전한 환경에서 전략을 테스트해볼 수 있어 초보 투자자에게 최적화된 학습 공간이 됩니다.

적용 기술
프레임워크 : Spring Boot
사용 언어 : Java, HTML5, CSS, JavaScript
데이터베이스 : MariaDB (회원/자산 정보), MongoDB (뉴스 스크랩 정보)
클라우드 : Amazon Web Services (EC2, RDS)
통신 프로토콜 : REST API
API 활용 :
한국투자증권 Open API (주식 시세 및 투자 지표)
업비트 Open API (암호화폐 시세 정보)
DART API (공시자료 조회)
공공데이터포털 KRX 상장종목 API
네이버 뉴스 Open API
한국은행 통계용어사전 API
기타 :
MyBatis, Thymeleaf, JQuery, Ajax
TradingView Lightweight Charts (캔들 차트 시각화)
Apache ECharts (대시보드 시각화)
IDE : IntelliJ IDEA
