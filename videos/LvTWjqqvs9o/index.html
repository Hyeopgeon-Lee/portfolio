PROJECT NOTES

작품을 더 자세히
살펴보세요.

설명: “EXPENSION”은 영단어 expansion과 pen의 결합어로,
‘펜을 들고 사고를 확장한다’는 의미를 담고 있습니다.
본 서비스는 AI 기반 독서·작문 보조 플랫폼으로, 사용자가 검색한 도서에 대해 다음 기능을 제공합니다:

1.독서 가이드-팁 생성
Naver·Aladin OpenAPI로 도서 정보를 수집하고,
OpenAI의 ChatGPT API를 통해 효과적인 독서 팁을 도출합니다.

2.글쓰기 가이드-질문 제공
독후 작문을 돕기 위한 질문을 자동 생성하여,
사용자가 쉽고 체계적으로 사고를 전개할 수 있도록 안내합니다.

3.작성 내용 저장·관리
MongoDB에 작성한 글을 저장하며, 언제든지 조회·수정·삭제가 가능합니다.

EXPENSION을 통해, 사용자는 장소에 구애받지 않고 편리하게 독서와 작문을 수행할 수 있으며,
개인화된 학습 경험을 누릴 수 있습니다.

적용 기술
프레임워크: Spring Framework
사용 언어: Java, HTML5, CSS, JavaScript
데이터베이스: MariaDB, MongoDB
클라우드: AWS EC2
프로토콜: SMTP, HTTPS
기타 요소: Bootstrap, spring JPA, Ajax, JQuery, jsoup, Thymeleaf
사용한 IDE: Intellij
사용한 API:
-Naver OpenAPI Search/Book
-Aladin OpenAPI
-OpenAI ChatGPT API-3.5 turbo
사용한 웹 서버: nginx
