설명 : 응팔(EungPal)은 "응급실 팔로우"의 줄임말로 사용자 증상(텍스트) 또는 상처 사진을 기반으로, AI가 간단한 응급처치 방법을 제안하고 주변 응급실 정보까지 제공하는 AI 융합 응급의료 서비스입니다.
사용자는 텍스트로 증상을 입력하거나, 상처 사진을 업로드할 수 있으며 AI는 이를 분석하여 응급 대처법을 제시하고, 공공데이터 기반의 실시간 응급실 위치 및 운영 정보를 제공합니다. 증상에 따른 조치 안내뿐만 아니라 병상 수, 거리, 운영 여부 등 현실적인 이동 판단에 도움을 줍니다.

적용 기술
Framework & Architecture : Spring Boot, Spring Security
Language : Java, HTML5, CSS, JavaScript
Database : MongoDB, Redis
Security & Auth : JWT, Spring Security
Cloud : AWS EC2, AWS S3
Performance : Spring Cache
IDE & Tools : IntelliJ IDEA, Git/GitHub
External APIs :
- OpenAI API (증상 분석 및 텍스트 생성)
- 공공데이터포털 API (국립중앙의료원 응급의료 정보 실시간 조회)
- Kakao Map API (응급실 위치 시각화)
- OpenWeatherMap API (날씨 표시)
