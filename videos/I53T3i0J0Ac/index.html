설 명 :

제안하는 프로젝트는 자바 기반 크롤링 도구인 Jsoup을 사용하여 여러가지 축구 관련 정보를 조회할 수 있도록 웹 어플리케이션을 제공합니다. 축구 기사, 선수단, 순위, 일정 및 결과 등등 사용자가 원하는 정보들을 조회할 수 있도록 구현하였습니다. 사용자가 회원가입 시에 팀을 선택하면 그 팀에 해당하는 정보들을 조회할 수 있도록 구현하였습니다. 또한, RestAPI를 이용하여 카카오 계정으로 로그인하는 기능을 통해 정보입력의 번거로움을 최소화하였습니다. 크롤링하는 값들은 스케줄러를 이용하여 일정 시간마다 갱신하였습니다. 이외에도 공지사항 게시판 및 관리자의 회원관리 기능을 구현하였습니다.

적용 기술

- 프레임워크 : Spring FrameWork

- 데이터베이스 : Oracle SQL Developer

- 적용 공공데이터(OpenAPI) : 카카오 계정 소셜 로그인 연동(RestAPI)

- 기타 : Ajax를 이용한 페이지 처리 Bootstrap를 이용한 디자인 Javascript 및 JQuery Jsoup을 이용한 축구사이트(BBC) 크롤링
