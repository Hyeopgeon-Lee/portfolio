설 명 :
BetterMorse는 본 개발자가 군에서 배운 모스부호 학습법을 토대로 모스부호를 배우고 싶은 사용자에게 학습법을 제공합니다.
학습법의 종류는 두 가지로, 사용자가 직접 모스부호를 입력하는 방식과 Sound를 듣고 해당하는 모스부호를 입력하는 방식이 있습니다.
Playground 기능은 사용자가 배운 모스부호를 SpaceBar와 Click 두 가지로 자유롭게 입력하며 놀이하는 페이지입니다.
Education 기능은 English, Korean, Number 세 가지의 문자 형태를 보고 직접 SpaceBar로 입력해볼 수 있는 페이지입니다.
Listen 기능은 모스부호 청취 역량을 기를 수 있는 기능들을 모아놓은 페이지입니다.
Learn Listen과 Learn Number 기능은 초보자를 위해 문자와 Sound를 같이 제공하여 청취 실력을 기를 수 있게 합니다.
Test Main 페이지는 레벨별로 Output Sound의 속도를 나누고, 답을 입력할 수 있는 화면을 제공합니다.
사용자가 답을 입력하면 사용자의 답변 배열과 문제의 배열을 비교합니다. 비교된 배열에서 틀린 문자들을 Counting하고
오름차순으로 정렬 후 최상위 3개에 해당하는 문자를 사용자의 DB인 MySQL과 MongoDB에 저장합니다.

적용 기술

- 프레임워크 : Spring Framework
- 데이터베이스 : MySQL, MongoDB
- 클라우드 : AWS EC2
- 기타 : Ajax, jQuery, WebAudioAPI
