설 명 :

CARFIX 는 공공데이터를 이용한 내주변 자동차 정비소 찾기 서비스로 개인프로젝트 웹 구현 시간을 통해 개발했다. 서울시 자동차 정비소 공공데이터를 이용하여 현재 위치를 통해 주변에 위치한 자동차 정비소를 찾아주고 카카오 지도로 연결 시켜주도록 구현한 웹이다. 자신이 다녀온 정비소에 대해 글을 작성하고 별점을 줄 수 있는 게시판이 구성되어있고, 마이페이지에서 자신이 작성한 글만 모아볼 수 있고 트위터나 네이버 블로그, 카페등에 공유할 수 있는 기능도 존재한다. 분실물을 검색하여 조회를 하면 각자의 분실물에 해당하는 상세정보를 확인할 수 있다. 검색기능을 통해 전국에 위치한 공식 자동차 서비스 센터의 위치도 찾아볼 수 있다. 회원탈퇴시 회원이 작성한 모든 글과 회원정보는 사라지게 되어있다. 해당 웹 구현을 통하여 사용자들이 한눈에 여러 정비소들의 위치를 알아보고 최적의 장소를 찾을 수 있을 것이다.

적용 기술

- 프레임워크 : 스프링 프레임워크, bootstrap

- 데이터베이스 : Oracle 11g

- 적용 공공데이터(OpenAPI) : 서울 특별시 자동차 정비소 정보

- 기타 : 카카오지도 API, jQuery, Javascript
