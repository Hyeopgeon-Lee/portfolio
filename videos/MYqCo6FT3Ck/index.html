설 명 :
T.H.E(Today Hilight English)는 근 7년간의 뉴스 + 매일매일 새로운 뉴스를 활용하여 문제 생성 및 학습을 제공하는 웹 어플리케이션이다.
본 프로젝트는 구글클라우드 TTS를 통해 발음 연습을 도와주며 Python Flask를 통해 음성의 높낮이를 분석하여 사용자에게 음성 높낮이 교정을 위한 그래프를 제시한다.
웹 애플리케이션 서버의 데이터 저장소는 MySQL, MongoDB을 활용하였다.

적용 기술

- 프레임워크 : 스프링 프레임워크(메이븐)

- 데이터베이스 : MySQL, MongoDB

- OpenAPI : 구글클라우드TTS, 카카오번역API, 네이버번역API,

- 기타 : JSOUP, Ajax, JavaScript, HTML5, BootStrap, Stanford_NLP

- Python, Flask
