작품 설명
뮤직이모션은 사용자의 감정을 분석하고, 그 감정에 어울리는 음악을 추천해주는 AI 감성 일기 플랫폼입니다.
사용자가 작성한 일기는 OpenAI GPT API를 통해 감정이 분석되고, 감정 키워드에 따라 Spotify API를 통해 음악을 자동 추천합니다.

일기, 감정 결과, 추천 음악 등은 MongoDB에 저장되며, 사용자는 감정 이모지와 함께 자신의 감정 히스토리를 일목요연하게 파악할 수 있습니다.
또한 감정별로 추천된 음악을 저장하거나 삭제할 수 있어, 감정과 음악을 연결한 자기 표현 및 감정 기록 도구로 활용됩니다.

뮤직이모션은 감정을 말로 표현하기 어려운 사용자에게 감정 탐색과 음악을 통한 치유 경험을 제공합니다.

적용 기술
프레임워크 : Spring Boot
사용 언어 : Java, HTML5, CSS, JavaScript
데이터베이스 :
MariaDB : 회원 정보
MongoDB : 일기 본문, 감정 분석 결과, 감정 키워드, 추천 음악 정보
AI 모델 : OpenAI GPT API (감정 분석 및 감정 키워드 추출)
통신 프로토콜 : REST API
API 활용 :
OpenAI GPT API (일기 감정 분석 및 감정 키워드 생성)
Spotify Web API (감정 기반 음악 추천 및 저장)
기타 기술 :
MyBatis, Thymeleaf, Bootstrap, JQuery, Ajax
Jackson (JSON 직렬화/역직렬화)
SweetAlert2 (모달 알림 및 사용자 인터랙션 처리)
IDE : IntelliJ IDEA
