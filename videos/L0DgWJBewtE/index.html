작품 설명
My Library 는 독서에 대한 입문자나 독자에 독후감 작성을 돕기 위해 제작한 웹 서비스입니다.
기본적으로 naver 책 검색 api를 통해 검색, 추천, 찜하기 등을 지원하며 책에 관한 정보를 받아와 독후감을 작성 할 수 있습니다.
원하는 시간 대에 일정을 추가하고 도서를 검색하여 도서에 대한 정보를 얻어 도서에 관한 독후감을 작성하여 사용자들과 공유해 의견을 나눌 수 잇습니다.
또한 Kakao Map API에서 제공하는 지도를 통해 도서관의 위치를 알 수 있습니다.

적용 기술
- 프레임워크 : Spring-Boot
- 사용언어 : Java, HTML, CSS, JavaScript
- 데이터베이스 : MariaDB, Reids
- 클라우드 : Amazon Web Services
- 기타 : JPA(Hibernate), Ajax, BootStrap, Thymeleaf
- IDE : IntelliJ
- API : KakaoMap API, Naver Search API
