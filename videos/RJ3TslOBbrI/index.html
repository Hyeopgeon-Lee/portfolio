설 명 : ‘급한불’은 서울에 위치한 공중화장실을 찾는 서비스입니다. 주변에 있는 공중화장실을 바로 표시해 주기 위하여 접속 위치는 카카오 지도API와 GeoLocation 기능을 사용하여 구현하였고, 서울 각 구에 해당하는 지역을 손쉽게 이동하여 찾을 수 있도록 지역 검색 또한 구현하였습니다. 공중화장실의 대한 데이터는 서울시 열린 데이터광장에 업로드 되어있는 서울시 공중화장실 위치정보 json파일을 사용하였습니다.또한, 리뷰 커뮤니티를 운영하여 공중 화장실을 이용할 때 문제점, 개선점 등의 대한 의견을 자유롭게 나눌 수 있도록 구현하였습니다. 관리자는 일반 회원들과 동일하게 이용할 수 있으며 관리페이지를 통하여 회원을 관리하고 전체 게시글을 관리 할 수 있도록 하였습니다. ‘급한불’은 앞으로 서울 뿐만 아니라 전국 공중화장실로 범위를 넓혀 나갈 계획입니다.

적용 기술
- 프레임워크 : Spring Framework
- 데이터베이스 : Oracle 11g
- 적용 공공데이터(OpenAPI) : 서울시 공중화장실 위치정보
- 기타 : Opinion Mining, Kakaomap API, Geolocation API
