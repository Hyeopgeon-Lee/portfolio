강아지는 훌륭하다 S2

설 명 :
강아지는 훌륭하다는 점차 늘어나는 반려인들을 위한 커뮤니티 웹사이트이다.
한국연구원KREI에 따르면 반려동물을 키우는 26.4%의 가구(약 591만 가구)중에 약 83.9%가 강아지를 키운다는 조사 결과가 발표되었다. 이를통해 강아지를 키우는 반려인들의 정보공유 공간의 필요성을 느껴 해당 서비스를 제작하였다.

주요 기능으로는
카카오 로그인을 구현하여 번거로운 회원가입 절차를 간소화 하였으며 회원 정보 또한 카카오와 연동하여 카카오의 정보만 확인 및 변경한다.

그리고 크롤링 기술을 통하여 견종백과와 실시간 동물 관련 뉴스를 제공하며,
혼자사는 직장인 또는 학생들을 위해 카카오 맵을 활용하여 지역별 강아지 유치원 위치 정보를 제공하고, 이는 아침에 많이 쓰이는 점을 생각하여 오픈웨더API를 활용해 실시간 날씨 정보를 서비스 가장 상단에 제공하고 있다.

또한 게시판과 실시간 채팅 기능을 추가하여 사용자들간의 정보교환 활성화를 유도하고 있다.

적용 기술
- 프레임워크 : Spring Framework(Maven)
- 데이터베이스 : MySQL, MongoDB
- 적용 데이터(Crawling) : HappyPet 뉴스 정보, BeMyPet 견종 백과
- 적용 API : KakaoLogin API (RestAPI), KakaoMap API, OpenWeather API
- 기타 : JavaScript, jQuery, Ajax, HTML5, Crawling, Bootstrap
- 클라우드 : AWS EC2
