설명 : AI 이미지 분석을 활용한 동물 정보 아카이빙 서비스입니다. 사용자가 동물 사진을 업로드하면, OpenAI Vision API가 이미지를 분석하여 동물의 이름, 학명, 위험도 및 상세 설명을 제공합니다. 분석된 정보를 바탕으로 iNaturalist API에서 전 세계의 관찰 기록을, 네이버 검색 API에서 관련 백과사전 및 최신 뉴스 정보를 자동으로 수집하여 종합적인 리포트를 생성합니다.
사용자는 분석된 결과를 개인 페이지에 저장하고 태그를 달아 관리할 수 있으며, 지도를 통해 기록한 위치를 한눈에 볼 수 있습니다. Spring Security를 적용하여 안전한 회원가입, 소셜 로그인(Google), 정보 수정 및 계정 연동 기능을 구현하였고, AWS S3를 통해 사용자 이미지를 안정적으로 관리합니다.
적용 기술
프레임워크 : Spring Boot
사용언어 : Java (17) , HTML5, CSS, JavaScript
데이터베이스 : MongoDB (NoSQL)
클라우드 : AWS (Amazon Web Services) - S3 for file storage
프로토콜 : HTTPS, RESTful API
기타 :
Template Engine: Thymeleaf
Security: Spring Security, OAuth 2.0

Library: Lombok, Jackson, JJWT
