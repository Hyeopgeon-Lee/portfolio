설명 : TrailAid는 AI분석과 위치 기반 서비스를 활용한 안전한 등산로 안내 및 상처인식 플랫폼입니다.
사용자의 위치를 바탕으로 초보자도 안전하게 등산할 수 있는 경로를 추천받을수 있습니다.
또한 사용자가 특정 지역의 등산로를 검색하고 경로를 탐색할 수 있도록 지원합니다.
사용자가 업로드한 상처 사진을 AI가 분석하여 부상 정도를 평가하고
상처 분석 결과에 따라 적절한 응급처치 방법을 추천하여 신속한 대처 방법을 안내합니다.

적용 기술
- 프레임워크 : Spring-Boot
- 사용언어 : Java, HTML, CSS, JavaScript
- 데이터베이스 : MariaDB
- 클라우드 : NaverCloud Platform
- 프로토콜 : WebSocket, HTTPS
- 기타 : Ajax, JQuery, BootStrap
- IDE : IntelliJ
- API : Yaralanmalar Computer Vision Project API, NAVER Map API, Geocoding API, Reverse Geocoding API, 2D데이터 등산로 API, 산림청 산 정보 조회 API
