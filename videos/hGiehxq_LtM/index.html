설 명 : 제로 웨이스트 챌린지는 일상 속 플라스틱 감소를 지향하는 사용자들의 인증샷 이미지 업로드 및 기록 확인이 가능한 웹 애플리케이션입니다. 사용자는 5가지 유형의 챌린지 타입중 한가지를 선택한 후 그에 맞는 인증샷 이미지 파일을 업로드 할 수 있으며 게시 후 수정,삭제가 가능합니다. 마이페이지에서는 챌린지 도전 일 수 및 기록 확인이 가능하고 사용자들간의 챌린지 기록 순위도 볼 수 있습니다. 그리고 서울시 자치구별 통합대기 환경지수 API를 활용해 대기오염 상태 정보를 실시간으로 시각화하였고 Kakao 지도 API를 연동해 친환경 제품을 구입할 수 있는 제로웨이스트 샵 정보도 제공합니다.

적용 기술

- 프레임워크 : Spring Framework
- 데이터베이스 : MariaDB, Redis
- 클라우드 : AWS EC2, RDS
- 기타 : 서울시공공데이터 Open API, Kakao 지도 API, JavaScript, Ajax, jQuery,
