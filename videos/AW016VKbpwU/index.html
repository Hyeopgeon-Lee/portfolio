설 명 :
제안하는 프로젝트는 자바 기반의 크롤링 도구인 Jsoup을 이용하여 도서 정보를 가져와 사용자가 활용할 수 있도록 만든 웹입니다. 스케줄러를 활용하여 일정 시간마다 크롤링하여 저장한 도서 정보를 카테고리 및 베스트셀러 별로 분류하여 사용자가 편리하게 사용할 수 있도록 구현하였습니다. 또한, 썸머노트를 활용하여 사용자가 임의의 책을 가지고 독서록을 작성할 수 있도록 하고 책을 관심도서로 추가, 삭제할 수 있도록 제작하였습니다. Cropper.js를 사용하여 사용자의 프로필 이미지를 추가할 수 있도록 하였고 로그인, 회원가입 시에는 Spring Security에 웹의 인증과 권한을 맡겨 보안 문제를 해결하였습니다.

적용 기술
- 프레임워크 : Spring Boot(Spring FrameWork)
- 데이터베이스 : MariaDB , Redis
- 기타 : JPA, Spring Security, Jsoup, Thymeleaf, Bootstrap, Jquery, AWS EC2, AWS RDS, 웹소켓, Rest API
