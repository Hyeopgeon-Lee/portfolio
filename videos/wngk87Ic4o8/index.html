설명 : QuizGarten은 "Quiz"와 독일어로 정원이라는 뜻인 "Garten"을 합한 단어로,
'퀴즈가 가득한 즐거운 정원'이라는 의미를 가지고 있습니다.
본 서비스는 퀴즈 제작 및 플레이 웹 플랫폼으로, 사용자에게 다음 기능을 제공합니다.

AI 퀴즈 생성 : 퀴즈 생성 시 설정된 카테고리를 기반으로 GPT가 자동으로 문제와 정답을 생성해줍니다.
이미지 퀴즈 : Cropper.js로 잘라낸 이미지를 S3 서버에 업로드하고, 정답을 직접 입력해 문제를 제작할 수 있습니다.
오디오 퀴즈 : S3 서버에 업로드 된 유튜브 링크를 Youtube iframe API로 불러와서 재생 할 수 있고, 정답을 직접 입력해 문제를 제작 할 수 있습니다.
객관식 퀴즈 : 사용자가 직접 정보를 찾아서 문제, 보기, 정답을 입력해 제작 할 수 있는 퀴즈입니다.
퀴즈 검색 기능 : 퀴즈제목을 입력하여 빠른 검색을 가능하게 합니다.
퀴즈 좋아요 / 북마크 기능 : 사용자가 선호하는 퀴즈를 좋아요 / 북마크 기능을 통해 저장할 수 있습니다.

적용 기술
프레임워크 : Spring Framework
백엔드 기술 : Spring MVC, Spring Security, HttpSession, Spring JPA
아키텍처 / 통신 방식 : REST API, JSON, AJAX
사용언어 : JAVA, HTML5, CSS, JavaScript
데이터베이스 : MongoDB(퀴즈정보), MariaDB(회원정보, 게시판, 퀴즈메타데이터)
클라우드 : Amazon Web Services (EC2, RDS, S3)
프로토콜 : HTTPS, SMTP
웹서버: Nginx
API Client : Spring Cloud OpenFeign
기타 : Cropper.js, JQuery, Thymeleaf
IDE : IntelliJ
API :
- OpenAI API (ChatGPT 3.5 Turbo)
- Youtube Iframe API
- Kakao API
