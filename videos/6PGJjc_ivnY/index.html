설명 : 과외해듀오는 대학생 혹은 경단녀를 선생으로 모집하고 대학에서 인정되는 봉사시간 및 급여를 정부에서 지급하여 일자리 창출과 학부모들의 사교육비 절감을 위해 기획한 서비스 입니다.
과외선생님을 찾고 학생과 선생을 매칭하여 숙제관리 및 일정관리를 할 수 있으며, 커뮤니티 혹은 채팅을 통하여 학생들간 소통 또한 가능하고, 원하는 과목의 선생님만을 찾아 신청할 수 있습니다.
또한 FaceID를 통한 로그인 기능 또한 구현하였습니다.

적용 기술
- 백엔드 프레임워크 : Spring-Boot
- 프론트엔드 라이브러리 : React
- 사용언어 : Java, HTML, CSS, JavaScript, TypeScript
- 데이터베이스 : MariaDB, MongoDB, Redis
- 클라우드 : Amazon Web Services
- 프로토콜 : WebSocket, SMTP
- 기타 : JPA(Hibernate), MUI, React Router, axios, TesorFlowJS, Face-API, Spring Open Feign
- IDE : IntelliJ, WebStorm
- API : 공공데이터포털 API(시도별 고등학생 사교육 참여율), OpenWeatherMap, Recaptcha v3
