작품 설명

SaveMate는 단순히 지출을 기록하는 것을 넘어, 데이터 분석을 통해 자신의 소비 습관을 객관적으로 파악하고 미래의 소비를 예측하여 계획적인 금융 생활을 돕기 위한 웹 서비스입니다.

MSA 설계를 도입하여 확장성을 높였으며, 사용자 간 소비 패턴 비교 분석 및 예산 초과 자동 경고 시스템을 통해 사용자가 주체적으로 소비를 관리할 수 있는 환경을 제공합니다.

또한, OpenAI API를 연동하여 AI 기반의 개인 맞춤형 재정 조언을 제공하고, 한국은행 ECOS API를 통해 경제 지표를 반영하는 등 외부 데이터를 활용한 심층적인 분석 기능으로 서비스의 가치를 더했습니다.

적용 기술

프레임워크 : Spring Boot 3.2.7, Spring Cloud

사용언어 : Java 17, HTML5, CSS(Tailwind), JavaScript

데이터베이스 : MariaDB, MongoDB

클라우드 : AWS (RDS, EC2)

프로토콜 : REST API

기타 : jQuery, Thymeleaf, Spring Security, Spring Data JPA/MongoDB, Gradle, Lombok

API : OpenAI API, 한국은행(BOK) ECOS API
