작품 설명
Global Ray는 전 세계 영문 뉴스를 AI가 자동으로 번역·요약하여 한국어로 제공하는 글로벌 뉴스 플랫폼입니다.

News API를 통해 경제·엔터테인먼트·종합·보건·과학·IT·스포츠 등 7개 카테고리의 영문 뉴스를 2시간마다 자동으로 수집하며, Jsoup으로 기사 원문을 크롤링한 뒤 Google Gemini AI가 제목 번역과 3줄 요약을 자동 생성합니다.

사용자는 관심 기사를 북마크하여 마이페이지에서 모아볼 수 있으며, AI 챗봇 기능을 통해 뉴스 관련 질의응답도 가능합니다. 일반 회원가입(이메일 인증) 및 Google OAuth2 소셜 로그인을 모두 지원합니다.

세션 기반 인증 구조와 BCrypt 비밀번호 암호화, CSRF 보호를 적용하여 보안성을 확보하였으며, AWS 클라우드 환경에 배포, 운영중입니다.

적용 기술
프레임워크 : Spring Boot 4.x, Spring Security

사용 언어 : Java 17, HTML5, CSS, JavaScript

데이터베이스 : MariaDB (회원, 이메일 인증), MongoDB (뉴스 기사)

클라우드 : Amazon Web Services (EC2)

통신 프로토콜 : REST API, HTTPS, SMTP

인증/보안 : 세션 기반 인증(JSESSIONID), OAuth2(Google), BCrypt, CSRF Token, SHA-256

API 활용 : News API, Google Gemini API

기타 : Thymeleaf, WebClient, JPA/Hibernate, Spring Data MongoDB, Jsoup(크롤링), Spring Scheduler(배치), Lombok
