Nexus Inventory (스마트 물류 재고 시스템)' 프로젝트를 소개합니다. 단순한 입출고 기록을 넘어, 외부 공공 데이터와 AI 기술을 결합하여 창고 관리를 지능적으로 도와주는 스마트 WMS(Warehouse Management System)입니다.
핵심 기능 (Key Features)
1.
지능형 수요 예측 (기상청 API 연동) 매일 날씨 데이터를 실시간으로 받아와 비 예보가 감지되면 우산, 우의 등 우천 관련 상품의 안전 재고량을 서버가 자동으로 상향 조정하고 관리자에게 실시간 알림(SSE)을 보냅니다.
2.
AI 창고 관리 비서 (Google Gemini API 연동) 재고 현황 데이터를 기반으로 구글 Gemini 생성형 AI가 창고의 문제점이나 발주가 필요한 품목을 분석해 스마트하게 답변해 주는 챗봇 기능이 탑재되어 있습니다.
3.
실시간 택배 위치 조회 (스윗트래커 API 연동) 출고된 상품에 운송장 번호를 자동 발급하고, 스마트택배 API와 연동하여 사용자가 화면에서 실시간 배송 이동 경로를 조회할 수 있습니다.
4.
튼튼한 보안과 회원 관리 (Spring Security) 일반 직원과 관리자의 권한을 분리하여 핵심 기능 접근을 제어하며, 이메일 전송을 통한 5분 타임어택 본인 인증과 카카오 주소 검색 기능으로 완성도 높은 회원가입을 구현했습니다.
5.
트래픽 제어 및 성능 최적화 Spring Cache와 Resilience4j(RateLimiter)를 적용하여 외부 API 호출 횟수를 방어하고 대규모 트래픽에도 서버가 다운되지 않도록 설계했습니다. 핵심 데이터는 MariaDB에, 비정형 로그 데이터는 MongoDB에 저장하는 다중 DB 아키텍처를 적용했습니다.

기술 스택 (Tech Stack)

Backend: Java 21, Spring Boot 3.4, Spring Security, Spring Data JPA

Database: MariaDB (RDBMS), MongoDB (NoSQL)

Frontend: HTML, CSS, JavaScript (Fetch API), Thymeleaf

External API: 기상청 단기예보 API, 구글 Gemini 3.1 AI, 스마트택배 API, 카카오 우편번호 API
