작품 설명
GagyeView는 AI와 OCR 기술을 결합하여 영수증을 자동 분석·등록해주는 지능형 가계부 플랫폼입니다.
Google Vision API가 영수증 텍스트를 추출하고, ChatGPT가 거래 내역을 정제·검증하여 2단계 자동 등록을 수행합니다. 사용자는 영수증을 촬영하거나 업로드하기만 하면 지출이 자동 기록되며,
AI 분석 리포트를 통해 월간 소비 패턴, 이상 지출, 항목별 통계를 직관적으로 파악할 수 있습니다.
또한 도넛·막대 차트 기반의 시각화를 통해 금융 데이터를 쉽게 이해할 수 있으며,
꾸준한 소비 습관 형성 및 합리적인 지출 관리에 도움을 줍니다.

적용 기술
- 프레임워크 : Spring Framework
- 사용 언어 : Java, HTML, CSS, JavaScript
- 데이터베이스 : MariaDB, MongoDB, Redis
- 클라우드 : AWS(EC2, ElastiCache, Aurora, DocumentDB)
- 웹 서버 : Nginx
- API : Google Cloud Vision API, OpenAI GPT API, Kakao Map API
- 프로토콜 : HTTPS, SMTP
- 기타 기술 : Ajax, JQuery, Bootstrap, Apache ECharts, Fabric.js
- IDE : IntelliJ IDEA
