설 명 :

갑자기 약속을 잡아서 함께 운동할 운동친구들이 없는 현대인을 위한

체육시설 예약을 돕는 웹 어플리케이션입니다.

사용자의 현재위치와 인근 체육시설위치를 보여주고, 경로안내 기능이 있습니다.

지역구/종목별 조회하여 선택한 체육시설종목을 예약/예약취소 할 수 있으며

저장된 예약 데이터를 지역구/종목별 이용현황으로 시각화하여 보여줍니다.

공지사항, 신고게시판(+댓글)과 같은 커뮤니티의 기능 역시 가지고 있습니다.

적용 기술

- 프레임워크 : 스프링프레임워크

- 데이터베이스 : Oracle 11g

- 적용 공공데이터 : (서울 열린데이터 광장)서울시 공공체육시설 현황

- 기타 : Chart.js, kakao 지도 API, Bootstrap, jQuery, JavaScript
