작품 설명

취업 취약 계층인 노년층에게 취업지원정보를 한 눈에 알기쉽게 보여주며

취업지원센터 정보를 지도로 보여주는 서비스입니다.

사용자는 이 서비스를 통해 다양한 취업 지원 프로그램 정보를 쉽고 간편하게 실시간으로 확인 가능하고,

유튜브 API를 통한 노인 취업 정보를 영상으로 확인 가능합니다.

적용 기술

- 프레임워크 : Spring-Boot

- 사용언어 : Java, HTML, CSS, JavaScript

- 데이터베이스 : MariaDB, MongoDB, Reids

- 클라우드 : Amazon Web Services

- 기타 : JPA(Hibernate), JQuery, Ajax, BootStrap, Thymeleaf, OpenFeign

- IDE : IntelliJ

- API : 서울 공공데이터 API, Kakao Map API, YouTube Data API
