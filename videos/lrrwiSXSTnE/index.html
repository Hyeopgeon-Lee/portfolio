설명 : 펫밀리는 유기동물 정보조회 API를 이용해 전국의 유기동물들을 조회할 수 있는 서비스입니다. 사용자는 검색된 유기동물에 대한 상세 정보를 확인할 수 있으며, 사진, 발견 장소, 현재 보호 상태, 나이, 성별 등의 정보를 통해 입양을 결정하는 데 도움을 받을 수 있습니다. 또한, 전국의 유기동물 보호소 정보를 제공하여 보호소의 위치, 연락처, 운영 시간 등을 미리 확인하고 방문할 수 있도록 돕습니다.

적용 기술
- 프레임워크 : Spring-Boot
- 사용언어 : Java, HTML, CSS, JavaScript
- 데이터베이스 : MariaDB, MongoDB
- 클라우드 : AWS, Mongo Atlas, Cloudtype MariaDB
- 프로토콜 : HTTPS, WebSocket
- 기타 : JPA(Hibernate), Ajax, JQuery, BootStrap, Thymeleaf, reCAPTCHA v3, Spring Cloud OpenFeign
- IDE : IntelliJ
- API : 공공데이터포털 API, 기상청 날씨 API, 카카오 지도 API, 네이버 로그인 API
