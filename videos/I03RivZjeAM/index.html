작품 설명
IntegriX는 텍스트, 이미지, URL을 분석하여 허위정보, 피싱 위험, AI 생성·합성·조작 의심 이미지, 위험 URL 여부를 확인할 수 있는 분석 플랫폼입니다.
사용자는 텍스트를 입력해 신뢰도, 위험 표현, 주요 판단 근거를 확인할 수 있고, 이미지 파일 또는 이미지 URL을 분석하여 AI 생성 및 조작 의심 신호를 확인할 수 있습니다.
URL 분석 기능은 HTTPS 연결 상태, SSL 인증서, URL 패턴, 단축 URL 여부, 신고 데이터, Google Safe Browsing API 결과를 종합해 안전·주의·위험 단계와 위험 점수를 제공합니다.
JWT 기반 Stateless 인증 구조와 Redis를 활용한 토큰 및 이메일 인증 처리를 적용했으며, MariaDB에는 회원·신고 데이터를 저장하고 MongoDB에는 분석 결과와 상세 이력을 저장합니다.
AWS EC2 서버에 Spring Boot 백엔드와 React 프론트엔드를 배포했으며, Nginx를 리버스 프록시로 사용해 외부 요청을 API 서버로 전달하고 정적 리소스 및 업로드 파일 접근을 처리합니다.
적용 기술
프레임워크 : Spring Boot 4.x, Spring Security, React
사용 언어 : Java 17, TypeScript
데이터베이스 : MariaDB, MongoDB Atlas, Redis
클라우드 : AWS EC2, AWS RDS
통신 프로토콜 : REST API, HTTP/HTTPS, SMTP
웹서버 : Nginx 리버스 프록시
인증/보안 : JWT Token, HttpOnly Cookie, BCrypt, Spring Security, Stateless 인증, CORS 설정
API 활용 : Google Safe Browsing API, 외부 LLM API
주요 기능 : 텍스트 신뢰도 분석, 이미지 AI 생성·합성·조작 의심 분석, URL 위험도 분석, 이메일 인증, 회원가입·로그인, 분석 이력, 대시보드, 신고 피드백
기타 : WebClient, JPA/Hibernate, Spring Data MongoDB, Spring Data Redis, Lombok, Axios, Recharts, Tailwind CSS
