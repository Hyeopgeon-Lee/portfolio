작품 설명

사용자에게 주변 병원 검색, 예약 기능, 그리고 업태별(전문과목별) 병원 검색을 제공하는 병원 위치 확인 서비스입니다. 사용자는 이 서비스를 통해 병원의 위치, 운영 시간, 진료 과목, 예약 가능 여부 등 다양한 정보를 실시간으로 확인할 수 있으며, 이를 통해 신속하게 필요한 병원을 찾을 수 있습니다.
주요 기능으로는, 먼저 서울 시 근처 병원을 검색하고, 사용자가 원하는 진료과목이나 병원 유형을 필터링하여 가장 적합한 병원을 찾을 수 있습니다. 또한, 예약 기능을 통해 사용자의 일정을 편하게 처리할 수 있습니다.

적용 기술

- 프레임워크 : Spring-Boot
- 사용언어 : Java, HTML, CSS, JavaScript
- 데이터베이스 : MariaDB, MongoDB, Reids
- 클라우드 : Amazon Web Services
- 기타 : JPA(Hibernate), JQuery, Ajax, BootStrap, Thymeleaf, OpenFeign
- IDE : IntelliJ
- API : 서울 공공데이터 API (서울시 병원 현황), Kakao Map API, YouTube Data API
