설 명 : 제안하는 프로젝트는 공공데이터포털( 제공하는 표준데이터를 기반으로 사용자가 원하는 등산로의 이름, 시간, 거리, 난이도를 제공합니다. 사용자는 제안하는 프로젝트의 사이트의 가입하여 회원가입 기능을 통해 사이트에 접속 할 수 있습니다. 등산로 이용 후 등산로 후기 게시판을 이용해 등산로 후기를 썸머노트를 사용하여 글씨체, 글씨크기, 폰트, 밑줄, 이미지파일 업로드를 사용 할 수 있으며, 트위터와 네이버에 공유 할 수 있는 등산로 후기 게시판을 구현 하였습니다. 그리고 관리자는 모든 게시판과 공지사항을 관리 할 수 있으며, 회원관리에 대한 제어를 할 수있습니다.

적용 기술

- 프레임워크 : Spring Framework 4.0

- 데이터베이스 : Oracle SQL 11g

- 적용 공공데이터(OpenAPI) : 전국 등산로 표준데이터

- 기타 : Ajax 기반 페이지 처리, BootStrap 4.0, Summernote WYSIWYG 에디터, CSS 라이브러리, D3.js 그래프 라이브러리, proj4js 라이브러리기반 좌표 변환, Kakaomap API
