설명 : Before The Flight는 비행기를 타러가기 전에 알면 유용한 정보를 제공하는 웹서비스입니다.
공항에 가기 전 사용자는 한국공항공사가 제공하는 국내 공항의 실시간 혼잡도 정보를 사전에 파악해 탑승 준비에 차질이 없도록 미리 대비할 수 있습니다.
또한 사용자는 YouTube Data API에서 제공하는 영상을 통해 비행기 탑승 전에 알면 유용한 안전 및 유의사항을 쉽고 재미있게 숙지할 수 있습니다.
이렇게 학습한 정보를 바탕으로 사용자는 웹소켓을 활용한 실시간 채팅을 통해 서로 정보를 공유하고 소통할 수 있습니다.

적용 기술
- 프레임워크 : Spring-Boot
- 사용언어 : Java, HTML, CSS, JavaScript
- 데이터베이스 : MariaDB, MongoDB
- 클라우드 : Google Cloud Platform
- 프로토콜 : WebSocket
- 기타 : JQuery, MyBatis
- IDE : IntelliJ
- API : 공공데이터포털 공항 혼잡도 정보 API, YouTube Data API, Naver Papago API
