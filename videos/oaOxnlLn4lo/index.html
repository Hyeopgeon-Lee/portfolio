작품 설명
"찍고 누르세요. 건강한 습관을 만들 수 있어요!"
캐치메디는 사용자의 처방전과 영양제 정보를 관리하고 복약 정보를 제공하는 프로젝트입니다.
OCR API와 의약품 API로 처방전을 스캔하여 간편하게 의약품 정보를 얻을 수 있습니다.
오늘의 약에서는 당일 복약 정보를 제공하여 먹어야 하는 약을 손쉽게 확인하고 카운팅할 수 있습니다.
또한 내 위치 주변의 약국 정보를 조회할 수 있고 실시간 채팅을 통해 관리자와 대화할 수 있습니다.

적용 기술
프레임워크 : Spring Boot
사용언어 : Java, HTML5, CSS, JavaScript
데이터베이스 : MariaDB, MongoDB
클라우드 : Amazon Web Service
프로토콜 : WebSocket
기타 : JQuery, Ajax, MyBatis, Thymeleaf
IDE : IntelliJ
API : Navdr Clova OCR, 의약품 개약 정보 e약은요, 전국 약국 정보, Amazon S3, Kakao Map, KakaoLogin, chatGPT
