설명 : 기상청 API와 인공지능 음성 변환을 통해 실시간으로 사용자가 설정한 지역의 해양 날씨를 제공하는 웹앱 플랫폼입니다. 해양 날씨를 알아보고자 들어간 기존 복잡한 날씨 제공 사이트들의 문제점을 개선하여 바다 날씨를 한 눈에 알 수 있게 보기 쉬운 UI/UX를 제공합니다. 또한 사용자들은 캘린더를 통해 선박 일정 관리 등이 용이해지고 연간 통계 데이터 제공으로 효율적인 성과 관리가 가능해집니다. 물날은 해양과 관련 된 더 많은 정보를 제공할 수 있도록 지속적인 개발 중에 있습니다.

적용 기술
- 프레임워크 : Spring Boot
- 개발 언어 : Java, HTML, CSS, JavaScript
- 데이터베이스 : MariaDB, MongoDB
- 클라우드 : AWS
- 기타 : JQuery, JPA, Spring Security, Ajax, Thymeleaf, Bootstrp
- IDE : IntelliJ
- API : 기상청 API, Google Text-to-Speech API, Kakao Map API
