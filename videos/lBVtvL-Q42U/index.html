작품 설명
UTGH은 장본 품목을 쉽게 관리하고 다양한 요리를 시도할 수 있도록 돕기 위한 서비스 입니다.

많은 사람들이 장을 보면서 구매한 식재료를 효율적으로 관리하지 못해 낭비하게 되는 경우가 많습니다. 또한, 매번 새로운 요리를 고민하는 데 많은 시간이 소요됩니다.

UTGH는 이러한 문제를 해결하고자 장 본 영수증 스캔을 통해 장본 품목을 쉽게 관리하는 기능과 등록된 식재료를 활용한 맞춤형 레시피를 추천하는 기능을 제공합니다.

적용 기술
- 프레임워크 : Spring Boot, Flask
- 사용언어 : Java, HTML, CSS, JavaScript, Python
- 데이터베이스 : MariaDB, MongoDB
- 클라우드 : Amazon Web Services, Naver Cloud Platform
- 기타 : MyBatis, Ajax, BootStrap, Thymeleaf, JQuery
- IDE : IntelliJ
- API : Naver Clova OCR API, Naver SmartEditor API, openAI API
