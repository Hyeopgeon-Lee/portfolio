설 명 :

파파고 랜덤채팅은 내 일상속의 이야기를 모르는 사람과 함께 나누며 서로의 문화를 공유하고,
1:1 의사소통을 장려하는 웹 애플리케이션이다.
본 프로젝트의 로그인 세션과 관리는 스프링 시큐리티를 커스터마이징하여 구현하였다.
채팅 유저 매칭은 Spring에서 제공하는 Async annotation을 사용하였다. 채팅 기능은 WebSocket(STOMP)을 통해 웹 애플리케이션 서버와 통신한다. 채팅 메시지의 언어감지, 번역은 Papago API를 활용하였다.

적용 기술
- 프레임워크 : Spring Framework 4.3.29

- 데이터베이스 : Oracle SQL Developer

- 적용 OpenAPI :
● 파파고 언어감지, 번역 API

- 기타 :
● Spring Security
● Jquery 3.2.1
● WebSocket(STOMP)
● Bootstrap 4.0.0
