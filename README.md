한국폴리텍대학 서울강서캠퍼스 빅데이터소프트웨어공학과의 학생 결과물을 소개하는 웹사이트입니다.

## 페이지 구성

- `/` — 학과 전체 포트폴리오 안내
- `/graduate/` — 우리학과 졸업생 허ㅇ혜의 대표 프로젝트 8개와 수상 성과
- `/projects/프로젝트명/` — 대표 프로젝트별 문제·기여 내용·기술·구현 화면
- `/showcase/` — 학과 졸업생·재학생 소프트웨어 시연영상
- `/videos/영상ID/` — 영상별 상세 설명과 소프트웨어 시연

시연영상은 학과 [YouTube 채널](https://www.youtube.com/@kopo-poly/videos)의 제목을 기준으로 분류했습니다.

- 2026년 7월 이전의 초기 프로젝트 영상은 프로젝트실습으로 분류합니다.
- 2026년 최종 졸업작품은 영상 제목을 우선 참고하되, 동일 작품에 후기 최종 발표가 있으면 앞선 영상은 초기 프로젝트로 분류합니다. 서로 다른 영상 ID는 모두 보존합니다.
- 전체 영상과 분류별 수량은 공개된 아카이브 데이터로 자동 계산합니다.

## 연결 주소

- 포트폴리오: <https://portfolio.k-bigdata.kr/>
- 학과 홈페이지: <https://ai.k-bigdata.kr/>
- 교수 기술 블로그: <https://prof.k-bigdata.kr/>

GitHub Pages 배포는 `.github/workflows/pages.yml`에서 자동으로 진행됩니다. 배포가 끝나면 사이트맵의 전체 URL을 IndexNow 참여 검색엔진에 자동으로 알립니다.

YouTube에 새 영상 설명을 작성한 뒤 `node scripts/generate-seo.mjs --refresh-youtube`를 실행하면 공개된 작품 설명과 적용 기술이 영상 상세 페이지와 영상 사이트맵에 반영됩니다. 개발자 이름, 연락처, 개인 블로그·주소는 반영하지 않습니다.

학과에서 확인한 2026년 최종 졸업작품 목표 수량은 16개입니다. GitHub Pages 배포 및 매일 오전 YouTube 동기화에서 원본 제목·실제 업로드 날짜·영상 ID를 확인하여 반영합니다. 동기화 결과가 16개와 다르면 해당 차이를 기록하고 확인할 수 없는 영상은 임의로 만들지 않습니다.

## 2026 영상 분리 기준

메인 화면과 시연영상 아카이브에서는 **2026년 프로젝트** 및 **2026년 졸업작품**을 서로 다른 목록으로 표시합니다.

- YouTube 원본 제목에 **졸업작품**이 있으면 최종 후보로 분류하되, 7월 이전 영상은 초기 프로젝트로 분류하며 같은 작품명의 더 최신 최종 영상이 있다면 앞선 영상도 프로젝트로 구분합니다.
- YouTube 원본 제목에 **프로젝트**가 있으면 초기 프로젝트로 분류합니다. 2026년 10월의 최종 발표와 6~7월의 초기 시연은 구분하며 각각의 YouTube 링크를 유지합니다.
- 제목 외에도 실제 게시 시각과 동일 작품명의 선후관계를 반영합니다. 원본 유튜브 피드에서 확인되지 않는 날짜·재생시간은 임의로 만들지 않습니다.
- 매일 채널을 재조회해 제목·업로드 정보에 따른 분류와 건수를 갱신합니다. 학과에서 안내한 최종 16개는 검증 목표 수량이며 실제 영상 메타데이터 없이 개수를 임의로 맞추지 않습니다.
- **2026 졸업작품 노출 순서**는 `data/2026-graduation-display-order.json`의 영상 ID를 우선합니다. 이 목록은 학과에서 요청한 순서를 보존하기 위한 표현 계층 설정이며, 유튜브 동기화의 날짜별 원본 순서와 무관하게 홈·아카이브에 적용됩니다. 지정하지 않은 작품은 기존 영상 목록의 상대 순서를 유지합니다.
