본 저장소는 빅데이터소프트웨어학과 졸업생 포트폴리오 예시 및

# 🎓 학과 소개

빅데이터소프트웨어학과는  
AI · 빅데이터 · 클라우드 · MSA · K-PaaS 기반의  
**실무 중심 소프트웨어 인재 양성 학과**입니다.

### 🔹 교육 특징
- AI / 데이터 분석 / 클라우드 네이티브 전문 교육
- 프로젝트 기반 실습 중심 커리큘럼
- 공모전·학술대회·해커톤 적극 참여
- 산업체 협력 및 취업 연계 프로그램 운영
- 최근 5년 평균 취업률 95% 이상

### 🔹 주요 진출 분야
- AI 개발자
- 데이터 엔지니어
- 클라우드 엔지니어
- 백엔드 개발자
- 금융 IT 개발자

# 🏆 연도별 주요 수상 실적

---

## 📅 2025년

- 서울시 **새싹(SeSAC) 해커톤 – 인공지능 소프트웨어 개발**
  → **대상 수상**

- 전라남도 **공공데이터 활용 서비스 구현 공모전**
  → **우수상 수상**

- 한국정보처리학회 추계학술대회
  → **우수논문상 수상**

- 과학기술정보통신부 주최 **한이음ICT 공모전**
  → **장려상 수상**

---

## 📅 2024년

- 과학기술정보통신부  
  **K-PaaS 클라우드서비스개발 공모전**
  → **OPA 의장상 수상**

- 한국정보처리학회 추계학술대회
  → **우수논문상 수상**

- 한국정보전자통신기술학회 추계학술대회
  → **우수논문상 수상**

- 과학기술정보통신부 주최 **한이음ICT 공모전**
  → **입선 수상**

---

## 📅 2023년

- 서울시 공공데이터 활용 공모전
  → **대상 수상**

## 📅 2022년

- 과학기술정보통신부 주최  
  **K-PaaS 클라우드서비스개발 공모전**

  → 장려상 수상

  → 우수논문상 수상

  → 특별상 수상
